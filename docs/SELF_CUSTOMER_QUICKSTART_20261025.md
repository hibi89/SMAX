# SMAX² SELF — 사장님용 오프라인 사용 안내 (검증 전 초안)

> **출시 전 테스트 문서.** 현재 배포·크몽 판매 전이며 아래 절차는 실제 Windows Edge/Chrome 검증 대기 중입니다. 상품 완성이나 구매 가능성을 주장하지 않습니다.

## 준비
- 판매자가 검증해 전달한 **`SMAX_SELF_OFFLINE.html`** 파일(정식 검증 후 배포 시). 첫 기능 체험용 예제는 HTML 내부에 들어 있어 CSV 파일을 따로 준비하지 않아도 됩니다.
- 최신 Microsoft Edge 또는 Google Chrome 브라우저. **프로그램 사용만 할 때 Node·Python 설치는 목표상 불필요**하며 실제 호환 검증은 아직 미완입니다.
- 업무 원본은 안전하게 **복사본**을 준비하세요. CSV 형식(UTF-8, 최대 2MB)만 지원하며 원본 Excel `.xlsx` 파일은 열 수 없습니다. Excel에서는 **파일 → 다른 이름으로 저장 → CSV UTF-8(쉼표로 분리)** 형식을 선택하세요. 기존 일반 CSV(CP949/EUC-KR)는 자동 변환하지 않으며, 잘못된 UTF-8 바이트는 파일 선택 단계에서 오류로 거부합니다.

## 어떤 템플릿에서 CSV를 처리할 수 있나요?
- **엑셀·CSV 통합**, **매출 집계·보고서**: UTF-8 CSV 선택·매핑·예제 체험·실제 결과물 다운로드 가능.
- **그 외 8종**: 자동화 설계 초안과 AI 구축 가이드 제공. **CSV 업로드·변환·외부 도구 실행은 지원하지 않습니다.** 실제 실행이 필요한 경우 앞의 2개 템플릿을 선택하세요.

## 합성 원본으로 파일 업로드 연습하기
1. **엑셀·CSV 통합** 또는 **매출 집계·보고서**에서 **연습용 원본 CSV 다운로드**를 누르세요. 각각 `SMAX_DEMO_SPREADSHEET.csv`와 `SMAX_DEMO_SALES.csv`를 로컬로 내려받습니다.
2. **CSV 자료 선택**에서 방금 받은 파일을 열고, 화면에 나타난 날짜·상품/채널·금액 원본 열을 **직접 선택**하세요. 데모 실행 버튼의 자동 매핑은 이 수동 연습에 적용되지 않습니다.
3. 실제 변환·잠정 보고서를 실행해 4행 중 검토 2행 또는 매출 5행 중 반영 2/제외 3, 잠정 순합계 79.90원과 비교하세요.
4. 합성 훈련용 파일은 UTF-8 BOM으로 저장되며 **가상의 데이터**입니다. 실제 매출/세금/거래증빙 또는 고객 파일로 제출하지 마세요.

## 설계 가이드 8종 — 내 업무에 맞게 작성하기
1. 재고, FAQ, 이메일, RAG, 견적, 예약, 웹 변화 감지, 리뷰 등 **가이드 전용 템플릿**을 선택하고 **챗봇 패널**로 이동합니다.
2. 질문에 답하고 오른쪽 **설계에 사용할 항목명 (직접 입력)** 칸에 해당 업무의 필드명만 적습니다. 예: 재고 템플릿의 상품명 필드에 `상품코드` 등을 기재할 수 있습니다.
3. 다른 칸으로 이동하면 입력한 항목명이 반영됩니다. **AX 설계서 JSON** 또는 **AI 구축 가이드**를 다운로드하여 미확정 내용을 직접 검토합니다. 입력한 필드명은 **미검증 설계 항목**으로 표시되며 모든 질문·필드를 채워도 현장 검토가 필요합니다. 실제 파일의 열이나 외부 시스템 연결이 확인된 것은 아닙니다.
4. **실제 원본 CSV 업로드·외부 API 실행·RAG 질의·메일 발송 등은 이 8종에 구현돼 있지 않습니다.** 단지 구축 요구사항을 더 구체적으로 적는 기능입니다. 필드명 이외에 고객 개인정보, 인증키, 실제 고객 원문은 입력하지 마세요.
5. 다른 템플릿으로 바꾸면 입력한 항목명은 저장되지 않습니다. 각 설계서 파일을 로컬에 따로 보관하세요.

## 처음 열었을 때 — 파일 없이 30초 체험
1. **엑셀·CSV 통합** 또는 **매출 집계·보고서** 템플릿을 선택하고 챗봇 패널로 이동합니다.
2. **합성 예제 바로 체험**을 누르면 예제 열에 한해 자동 매핑 후 로컬 변환 결과를 보여 줍니다. CSV 정리는 4행 중 검토 2행, 매출 집계는 5행 중 반영 2행·제외 3행·잠정 순합계 79.90원을 표시합니다.
3. 화면의 **합성 예제 체험 중** 문구를 확인하세요. **실제 거래/매출이 아니며, 업무 판단에 사용할 수 없는 가상 자료**입니다.
4. 합성 예제에서 저장한 파일은 `SMAX_DEMO_STANDARDIZED.csv`, `SMAX_DEMO_SALES_REPORT.csv`, `SMAX_DEMO_SALES_REVIEW_ROWS.csv`처럼 **`SMAX_DEMO_` 접두어**를 사용합니다. 실제 업무 결과 파일과 구분하고, 업무 제출에 사용하지 마세요.
5. 체험 중 **설계서 JSON**과 **AI 구축 가이드**를 다운로드하는 경우에도 파일명이 `SMAX_DEMO_`로 시작하며, 내용에 **합성 예제 경고**가 포함됩니다. 실제 업무 지침으로 전달하지 마세요.
6. 자신의 CSV를 선택하면 예제 결과·자동 매핑은 폐기됩니다. **실제 파일에서는 열을 직접 확인·선택**한 뒤 변환해야 합니다. 내부 예제는 외부 서버에 보내지지 않습니다.

## 해보기
1. `SMAX_SELF_OFFLINE.html` 파일을 컴퓨터에서 두 번 클릭하여 브라우저로 엽니다. 파일이 열리지 않거나 화면이 비면 제품 지원 절차에 따라 문의/대체 전달방식을 확인합니다. 외부 사이트로 파일 업로드하지 마세요.
2. '템플릿 패널'에서 **엑셀·CSV 통합**을 선택하고 **챗봇 패널**로 이동합니다.
3. CSV 파일을 선택합니다. 예제의 열은 `거래날짜`, `품목`, `결제금액`입니다.
4. 화면의 드롭다운에서 `거래일→거래날짜`, `상품명→품목`, `금액→결제금액`을 **직접 선택**하세요. 자동 후보는 확정이 아닙니다.
5. **매핑 확인 후 변환·미리보기** 클릭. 4행이 모두 남아 있어야 하며 3번째 데이터 행의 중복과 마지막 행의 날짜/금액 오류는 검토 대상으로 표시됩니다.
6. 검토 사유를 확인한 후 **전체 결과 CSV 다운로드**를 누르면 `SMAX_STANDARDIZED.csv`가 저장됩니다. 이 파일에는 정상 행과 검토 행이 **모두 포함**되며 원본을 수정하지 않습니다. 검토할 행이 한 건이라도 있으면 **검토 필요 행만 CSV 다운로드** 버튼도 표시됩니다. `SMAX_STANDARDIZED_REVIEW.csv`에는 같은 헤더와 검토 행만 남고 원본 레코드 번호·검토 사유가 유지됩니다. 검토 행이 없으면 버튼이 나타나지 않습니다. 합성 예제 사용 중에는 파일 이름 앞에 `SMAX_DEMO_`가 붙습니다.
7. Excel에서 한글이 깨지는 경우 결과 CSV를 UTF-8로 가져오기 하세요. 복잡한 회계·세금·재고 판단은 결과만 믿지 말고 업무 담당자가 확인해야 합니다.

## 주의
- 화면은 규칙형 안내입니다. 자동으로 이메일 발송, 주문·결제, ERP 수정, 생성형 AI 추론을 수행하지 않습니다.
- 비정상 날짜, 금액, 빈 값, 중복값, 위험한 수식 문자열은 가능한 경우 `NEEDS_REVIEW`로 남기며 사용자가 판단하도록 합니다. 모든 변환을 검증 없이 회계·법적 증빙으로 사용하지 마세요.
- **중복 판정 안내(2026-10-26):** 날짜·품목/판매채널·금액이 같더라도 CSV에 주문번호 등의 추가 열이 있고 서로 다른 값이라면 별개 거래로 처리합니다. 선택한 3개 열과 나머지 원본 열이 함께 같으면 중복 검토로 표시됩니다. **주문번호 등 구분 가능한 열이 없는 자료의 동일 금액 반복 거래는 중복 의심으로 매출 잠정 집계에서 제외될 수 있으므로** 반드시 제외/검토 행 CSV를 확인하고 실제 거래와 대조하세요. 원본 파일은 변경하지 않습니다.
- **금액 표기 주의(2026-10-26):** 같은 주문의 금액이 `100`, `0100`, `100.00`, `₩100원`처럼 표시만 달라도 중복 검토로 분류됩니다. 원본 파일과 CSV 출력의 금액 문자열은 그대로 유지하며, 이 중복 판정은 확정 회계 판단이 아닙니다. 검토 전용 CSV의 원본 번호를 확인하세요.
- 브라우저 로컬 실행을 목표로 만들었으며 사용자가 별도 동의하지 않으면 파일을 회사 서버나 SMAX로 업로드하지 않습니다. 다만 사용자가 다른 AI 서비스에 설계서 내용을 복사하는 것은 별도 전송입니다.
- 이 단일 HTML에는 실행 스크립트가 포함됩니다. 구매자별 라이선스·업데이트·지원 조건 및 배포방식은 최종 출시 전 별도로 고지합니다.
- 문제가 생기면 **원본을 보존**하고 프로그램/브라우저 버전, 합성 재현 파일, 오류 화면을 확인합니다. 민감한 고객 원본·개인정보·토큰을 채팅·GitHub에 올리지 않습니다.

## 추가 시험 기능 — 일별·월별 매출 집계 (출시 전)
1. 템플릿에서 **매출 집계·보고서**를 선택하고 **챗봇 패널**을 여세요.
2. UTF-8 CSV 파일을 선택합니다(2MB 이하). `판매일`, `판매채널`, `판매금액`에 해당하는 **각기 다른 원본 열**을 직접 선택합니다. 정확히 맞는 열이 없다면 집계를 중단하세요.
3. **집계 주기: 일별/월별** 중 하나를 선택하고 **매핑 확인 후 매출 집계**를 누릅니다. 채팅에서 일별·월별을 고르면 이 주기와 연동되며, CSV 파일을 다시 선택해도 선택한 주기는 유지됩니다. **주별 집계는 아직 지원하지 않습니다.**
4. 원본·반영·제외/검토 행수와 순합계를 확인합니다. 제외된 거래가 있으면 **원본레코드 번호와 제외 사유를 화면에서 처음 최대 5건까지** 확인할 수 있습니다. 화면 미리보기는 일부만 보여주므로 **잠정 집계 CSV** `SMAX_SALES_REPORT.csv`와 **제외/검토 행 CSV** `SMAX_SALES_REVIEW_ROWS.csv`를 **각각** 다운로드합니다. 검토 CSV에는 화면 미리보기에서 생략된 행까지 전부 포함됩니다.
5. 집계에서 제외된 행을 수동으로 검토한 뒤 원본 **복사본**의 날짜·금액·채널 데이터가 올바른지 확인하세요. 매핑이나 주기를 변경하면 이전 결과는 폐기되며 재실행이 필요합니다.

**금액 앞자리 0:** 매출 잠정 집계는 숫자 앞의 0을 제외한 실제 금액의 크기로 상한을 판단합니다. 예를 들어 `0000000000001`은 1원으로 반영할 수 있지만 1조 원 이상의 단일 금액은 여전히 검토 대상으로 제외합니다. 원본 표기는 바꾸지 않으며 동일 주문의 `1`과 `0000000000001`은 중복 검토로 분류합니다.

**주의:** 이 기능의 합계는 정상처럼 보이는 행만 임시 집계합니다. 중복·잘못된 날짜·결측값·수식 위험·과대금액은 기본 제외되며 누락된 금액이 있을 수 있습니다. 음수는 반품으로 자동 판단하지 않고 **음수 조정액**으로 별도 기재합니다. 세무신고·정산확정·자동 환불/지급에 사용하지 마세요. 기존 문서의 Windows 실기기/최신 릴리스 전체 검증 전 **실제 구매자에게 전달하지 않습니다**.
