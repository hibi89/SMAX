# SMAX² 캐릭터 결정 — 스몽이

기록일: 2026-10-25 KST · 최신 창업자 결정

- **SMAX²의 현재 캐릭터 이름은 '스몽이'로 확정한다.**
- 기준 후보는 사용자가 선택한 **고양이 귀가 달린 친근한 로봇** 이미지다.
- **세부 외형·색상·포즈·이미지 스타일·홈페이지 배치·상품화는 확정하지 않는다.** 실제 웹을 사용하면서 얼마든지 바꿀 수 있다.
- **NAON2(나온이)**는 미래에 등장할 수도 있고 등장하지 않을 수도 있다. 출연·확장 계획에 포함하지 않는다. 과거의 맥콩 및 NAON2 이미지는 참조 자료로만 보존한다.
- 캐릭터 사업·굿즈·교육용 파생 버전 등 **추가 확장 계획은 현재 수립하지 않는다**.
- 지금 우선순위는 SMAX² 사장님용 웹/SELF 기능 구현과 검증이다. 이후 필요할 때 디자인을 다시 결정한다.

이 문서는 **이름 선택만 고정한 최소 의사결정 기록**이다. 과거 스몽이 콘셉트 확장·굿즈·교육 응용 아이디어보다 우선한다. 기존 시안 삭제나 실제 사이트/상품 공개를 뜻하지 않는다.
