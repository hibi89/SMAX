# SMAX² 캐릭터 최신 결정 — 스몽이
2026-10-25 KST / 사용자 직접 선택

## 확정할 것
- **현재 SMAX² 주 캐릭터의 이름은 '스몽이'**. 사용자가 새싹 대신 다른 머리 장식을 요청하여 만든 3종 이미지(볼캡·고양이귀·프로펠러) 중 **가운데 고양이 귀가 달린, 흰색/연보라·하늘색 로봇 '스몽이'를 직접 선택**.
- 기본 정체성: **로봇 본체, 큰 보라 눈, 청록빛 화면 테두리, 보라색 양옆 이어패드, 위쪽 고양이 귀, 다정한 표정, 초보자 친화적 분위기**. 머리 위 새싹/볼캡/프로펠러는 선택된 기본안이 아님.
- **NAON2(나온이) 아날로그/디지털**은 공식 철자와 과거 시안을 보존하지만, **SMAX² 1차 홈페이지에는 넣을 필요 없고 장기적으로 등장할 수도/아예 등장하지 않을 수도 있는 후순위 캐릭터**. '미래에 반드시 등장', '현재 홈페이지 주인공'처럼 다루지 않음.
- 과거 **맥콩**은 이전 시안/선정 이력으로만 보존. 동일하게 현재 주캐릭터가 아님.
- 스몽이를 사장님·학부모·아이들 누구나 친근하게 받아들이도록 설계. **최첨단 네온·사이버펑크·과시형 3D보다 이해하기 쉬운 친근하고 귀엽지만 유치하지 않은 느낌**. 밝은 중성/파스텔 화면을 선호하되 실제 웹 UX 확인 후 조정.

## 아직 최종 승인하지 않은 것
- 캐릭터 **이름과 고양이귀 로봇이라는 기본 정체성은 확정**. 그러나 **세부 외형/표정·의상·2D/3D·화면 배치·색조·기능별 포즈 및 로고 조합은 다양한 이미지 시안을 보고 최종 검토**.
- 전역 UI와 굿즈 공식 디자인 최종 승인 보류 방침은 `docs/DESIGN_APPROVAL_DEFERRED_WEB_FIRST_20261025.md`를 유지. 스몽이 선정이 웹 전체 디자인 동결이나 상업 출고 승인은 아니다.
- 생성된 개념 일러스트는 그림/기획 참조이며 상업용 정식 SVG/투명 캐릭터 소스·브라우저 반영·배포/굿즈 제작을 자동 의미하지 않는다.

## 추후 웹 적용 순서
1. 기능/화면/업무 흐름 구현과 테스트를 우선한다.
2. 친근한 2D 스티커, 간소화 3D 안내자, 반응형 마스코트, 감정/포즈 시리즈, 교육 버전 등 **스몽이 시안 복수안**을 비교한다.
3. 실제 사용성 검증 후 한 기본 스타일과 제한된 보조 포즈를 최종 승인. 보조 캐릭터 추가, NAON2 활성화는 사용자의 별도 결정만으로 시행.
