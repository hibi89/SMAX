# SMAX 크몽 등록 초안 · 2026-10-25

> **등록 전용 초안. 아직 상품 미등록/판매 없음.** 제품 실사용·Windows 패키징 검증 뒤 확정.

## 제목 후보
SMAX — 사장님이 직접 만드는 업무 자동화 설계·학습 도구

## 소개
업무를 자동화하고 싶지만 어디서부터 시작해야 할지 막막한 분을 위한 셀프 AX 학습 프로그램입니다. 정해진 업무 템플릿 중 하나를 고르고, 질문에 답하고, 자신의 자료의 필드 구조를 확인하면 업무 표준화 설계와 외부 AI 구축 요청서/테스트 체크리스트를 받습니다. 고객 스스로 ChatGPT/Gemini/Claude, n8n, Google Sheets 등 선택한 외부 도구를 설정하도록 돕는 **설계·교육 도구**이며, 판매자가 고객 계정에 접속하거나 외부 자동화를 대신 설치하는 계약이 아닙니다.

- SMAX SELF 희망가 **50,000원** — 이용권 기간·환불 정책 미확정
- SMAX GUIDE 선택 추가 희망가 **50,000원** — 비동기 문자 학습 지원, 지원 횟수/기간 미확정
- 초기 10개 가이드 템플릿 목표. AI API 호출 필수 아님. 외부 AI 및 앱 사용료는 별도.
- 원본 고객 데이터는 고객 자신의 PC에서만 입력/검토. 실제 외부 AI에 보내는 데이터의 개인정보·기밀/권한 확인 책임은 고객에게 별도 안내.
- **현재는 초기 브라우저 시연 코드 단계**. Windows 독립형 설치, XLSX, 실제 업무 자동화 실행 검증 전이므로 완제품처럼 상품 등록하지 않는다.

## 등록 전 필수 확인
1. 크몽 전문가 인증/프로필과 카테고리 등록 자격, 상품 심사 절차.
2. 프로그램 실제 실행 파일 또는 제공 방식·지원 OS, 핵심 기능과 샘플 결과의 실제 재현.
3. SELF 라이선스/갱신·무료 수정/환불 기준, GUIDE 문의 수·유효 기간·응대 시한.
4. 회사/브랜드 이름 'SMAX' 유사상표 사용 가능 여부, 전자상거래상 표시 의무.
5. 외부 AX Lab 홈페이지 링크를 **크몽 상세페이지에 넣을 수 있는지** 플랫폼에 확인. 크몽 외부 직결제·대화 유도는 금지. 홈페이지 → 실제 크몽 상품 구매 링크는 등록 후 검토.
6. 공식 홈페이지는 별도의 **정적 쇼룸**. 상품명·가격 변경 가능하더라도 크몽 측의 수정·심사·페이지 유지 정책을 확인한 후 기존 상품 URL을 고정 링크로 사용.

원칙: 데모/미구현과 실제 설치 상품의 기능을 혼동하지 않으며, 판매 승인 전에는 상품등록 하지 않음.
