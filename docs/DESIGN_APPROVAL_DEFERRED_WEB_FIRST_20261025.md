# SMAX² 디자인 최종 승인 보류 — 웹 기능·UX 우선 원칙
기록: 2026-10-25 KST / 창업자 최신 직접 지시 / 디자인 '동결'을 해제하는 결정

## 0. 최신 결정
창업자: **"일단 디자인관련된 깃헙내용 뭐뭐있노 디자인을 확정하면안되겠다 웹구현해놓고 컨셉에맞게해야겟어"**.

**즉시 효력:** 과거 문서에서 로고·캐릭터·홈페이지·굿즈를 '공식/최종 확정'으로 표현했더라도, **최종 시각디자인 승인은 보류**. 기존 결과물/시안은 **참고 레퍼런스와 의사결정 이력으로 보존**. 창업자가 웹 기능 및 실사용 흐름을 확인한 뒤, 사용자에게 맞는 일관된 브랜드 시각 체계를 다시 비교·결정한다. 별도 승인 없이 기존 시안 삭제·로고 도형 수정·대량 이미지 생성·인쇄 주문·상업 배포를 하지 않는다.

## 3. 작업 우선순위
1. **실기능 완성:** 로컬 CSV 변환/다운로드, 템플릿 검색·질문 안내, 테스트와 예외 처리, 공개 사이트 대 유료 SELF 코드 경계. 이미 다른 브랜치의 변경 사항은 HEAD/CI 확인 후 중복 수행하지 않는다.
2. **정보 구조와 사용성:** 고객의 문제 발견 → 템플릿 탐색 → 시연/실행 → 결과 확인. 모바일 동선/접근성/정직한 기대치 표기.
3. **통합 웹 화면 실제 시연:** 임시 테마로 기능/사용 흐름 검증. 정식 공개 배포는 별도 사용자 승인, 유료 코어 공개 차단 후.
4. **콘셉트 선택:** 제품의 실제 핵심 장면에 맞춰 아날로그·디지털 NAON2, 로고, 색/폰트, 굿즈 연계 비율을 다시 평가하고 창업자 최종 승인을 받는다.
5. **검증된 최종 아트워크:** 고해상도 SVG/투명 배경 원본 및 반응형/가독성/인쇄 테스트. 비용/상표/실물 제작은 승인 게이트.

## 4. 금지·현재 증거
- 사용자가 요청하지 않았는데 디자인 확정처럼 새 결과물 8장씩 생성하거나 굿즈 제작을 우선하지 않는다.
- 초안 CSS의 `X` 중앙 진한 사각 오버레이가 진짜 겹친 사선의 기하와 일치하는지는 재검토; 굿즈 이미지의 마름모 후보도 선택지일 뿐 현재 공식 도형 아님.
- 디자인을 보류한다고 기존 브랜치/코드를 리셋하거나, 기능 테스트를 생략하거나, 공개/유료 코드 분리 없이 `site/` 전체를 Cloudflare에 배포하지 않는다.
- 본 문서는 **전략/승인 상태 기록**. 실제 홈페이지 디자인을 새로 구현/테스트/배포하거나 이미지 원본을 GitHub에 업로드한 것으로 주장하지 않는다.
