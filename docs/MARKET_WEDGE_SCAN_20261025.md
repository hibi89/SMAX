## 4. B가 고객 검증을 통과할 때의 제품 약속 초안
**문제:** 서로 다른 거래처의 XLSX/CSV 2~3개를 사람이 수식/눈으로 맞춰보면서 수량·단가·중복·미입고·누락을 놓침.
**SMAX 약속:** '파일을 올리면 회사별 열 이름을 SMAX 표준에 맞춰 매핑 제안 → 검토/확정 → 원본 행 근거를 단 불일치 보고서와 수정 후보를 내보냄'.
- 첫 드라이런: **발주서 vs 거래명세서 2-way match**, 입고내역은 다음 확장 3-way 선택입력.
- 허용: CSV/XLSX, 규칙표, 수량/가격/중복/미매칭/부분입고/허용오차, 원본 행 추적, 읽기 전용 다운로드.
- 초기 금지: 문서 이미지 OCR, ERP 쓰기, 발주 발송, 송금, 계좌 연동, 고객별 코드, 무승인 실행.
- AI는 필드/규칙 **후보** 제안에만 사용. 모순/애매함은 **NEEDS_REVIEW**로 안전중단. 산술 대조·중복 판정은 결정론적.
- 데이터 최소화: 로컬 합성 입력 먼저. 실제 고객 자료를 외부 LLM로 업로드하지 않음. 보안/동의 없이 서버 보관 없음.
