1. **P0:** 동작하는 로컬 변환 결과물 1종, 오류·중복·검토 안전성, 재현 테스트.
2. **P1:** 사장님 UX·템플릿 검색/맥콩 안내·사용 가이드, 브라우저 QA.
3. **P1:** 정적 무료 사이트와 유료 SELF 코드 분리, 실제 패키징·전달 방식.
4. **P2:** 두 번째 현업 로컬 도구(가능하면 간단 매출 집계) 및 가이드.
5. **P3 이후:** WEB 고객 인증/유료 URL 사용권, 학생·학부모 존, 공백상권 추천, 제안/수주의뢰 게시판, 캐릭터 굿즈, 정부사업 협력.

## 제품/브랜드/판매 원칙
- 상위 미션: **저렴한 AX 대중화·참여형 광장**, 창업자 주도 운영; 출구전략/기업가치 달성이 개발 우선순위를 왜곡하지 않게.
- SMAX² = SMAX Square, 공식 마스코트 **맥콩** (사용자 선정 로봇 이미지 원본이 디자인 기준. 기존 시안 변경/폐기 금지).

- 클라우드 공개 및 정식 상용 판매는 전제 조건 충족과 창업자 별도 승인 전 실행하지 않는다.
