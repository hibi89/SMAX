# SMAX² Square — 1차 홈페이지·크몽 거래 분리 및 미래 기능 게이트
결정일: 2026-10-25 KST / 승인: 사용자 “사이트결제되면 크몽차단 ... 훗날 디벨롭 ... 니가 판단” / 범위: 제품·UX 운영 정의. 상용 배포/상품판매 아님.

## 0. 최우선 기준
**1차 사이트는 사장님 존(정보·탐색·검증된 무료 미리보기)이며, 거래는 크몽 안에서만 진행.** 회사 홈페이지가 존재한다는 사실만으로 크몽이 자동 차단한다는 의미는 아님. **크몽에서 유입된 거래를 외부 결제/직거래로 유도하거나 실행하는 행위가 제재 대상**. 가격, 구매·안내 링크, 거래 중 대화 채널을 혼동하지 않음. URL 포함/외부 데모 링크 허용 범위는 크몽 담당자의 명확한 답변과 상품 심사 기준을 확인한 뒤 결정.

## 1. 1차 운영 화면 (사장님 존만 실제 오픈)
1. **헤더:** SMAX²(스맥스 스퀘어), 사장님 존 현재 이용 가능; “템플릿”, “이용 방법”, “광장 소개”, “상품 안내” 정도만. 로그인/회원가입/장바구니/내 포인트/직접 결제 버튼 **표시하지 않음**.
2. **첫 화면:** 사용자가 하는 반복 업무의 문제와 해결 방식을 명확히 알리고, 친근한 로봇 **맥콩**은 브랜드 안내자로 활용. 사용자가 업로드한 맥콩 레퍼런스(연보라·새싹·보라 이어패드)가 기준. 원본 자산이 확보되기 전 임의의 로봇 그림을 공식 이미지로 게시하지 않음.
3. **템플릿:** 10종 목록·사전형 검색·템플릿 상세·질문형 단계 안내는 현재 프로토타입의 범위에 따라 노출. 10종 모두 실제 업무 처리가 끝나는 제품이 아니므로 **‘자동으로 완성’ 같은 보장 문구 배제**, 미구현 템플릿은 ‘설계 가이드/준비 중’으로 표시.
4. **체험:** 공개 사이트에 올릴 무상 데모는 검증된 합성 샘플·교육 설명·템플릿 미리보기에 한정. 지금 `site/app.mjs` + `site/core.mjs`에 CSV/Blueprint 다운로드가 포함돼 있어 현재 전체 `site/`를 그대로 공개 배포하면 유료 유사 기능이 공개될 수 있음. 공개/유료 코드 및 실행 권한 분리 검사 **필수**.
5. **이용법:** ①업무 고르기 → ②구조/필요 자료 확인 → ③외부 AI/도구에서 직접 구축 또는 검증된 로컬 간단 도구 사용; **자체가 임의의 Gmail/ERP/RAG 작업을 자동 대행하지 않음**.
6. **상품 안내:** 크몽 상품 등록 전에는 **‘준비 중’**만 표시. 현재 ₩50,000 +₩50,000은 내부 희망 가격으로 확정 가격처럼 공개하지 않음. 등록 후 확인된 상품 링크가 있으면 공식 크몽 안전결제 경로 **사이트 → 크몽** 안내를 심사/정책 확인 후 노출. **크몽 → 개인 사이트 → 별도 결제** 유도 금지.
7. **광장 소개:** 의견·템플릿 참여 철학을 설명하되 게시판/댓글·통계·사례·후기를 실제 운영하는 것처럼 보이지 않게 표시. 사용자 실회사 파일이나 개인 정보 수집 금지. 실제 기업 리뷰·회원 수·성과 실적은 증빙 전 표시 금지.

## 2. 구매 및 지원 실제 흐름
**사이트 둘러보기 → 검증된 무료 미리보기 → (실제 등록되면) 크몽 상품 안내 → 크몽 안전결제 → 크몽 계약 조건대로 결과물 전달/대화.**
- 고객 계정·결제카드·주소/실회사 파일을 1차 사이트에서 받을 필요 없음.
- SELF는 검증된 로컬 배포 프로그램. GUIDE는 크몽 판매 범위 내 비동기 문자 지원만, 실제 정식 상품 게시 전 상품 설명·유효기간·환불 조건 확정.
- 별도 운영 고객 지원 사이트나 외부 메신저로 크몽 거래 협의 유도 금지.
- 결제 후 외부 WEB 사용권 전달 방식은 향후 크몽 정책/거래 조건 확인 필요. 크몽 결제 후 사용자에게 링크를 주는 구조가 **모든 유형에서 자동 허용된다고 간주하지 않는다**.

## 3. 미래 확장 슬롯 (현재 실제 기능으로 노출하지 않음)
| 우선 | 기능 | 발동 조건 |
|---|---|---|
| P2 | **유료 WEB 완성형 자동화** | SELF 검증, 서버 측 유료 권한/로그인/출력, 요금/운영기간/보안 테스트, 구매 경로 및 플랫폼 규정 확인 |
| P3 | **학생·학부모 배움의 광장** | 연령별 커리큘럼, 교육영상/실습 검증, 아동 보호자 동의/개인정보 설계 및 콘텐츠 운영 주체 확정 |
| P3 | **공백상권 추천** | 독립 공백상권 프로그램 사용자 가치 확인/기능·가격/입점 배너 조건 확정; 사이트 내부 결제로 이어지지 않게 분리 |
| P3 | **템플릿 커뮤니티/제안 제출** | 실제 저장·검토/운영·신고·삭제·저작권/개인정보 처리 규칙, 스팸·불법콘텐츠 대응 |
| P4 | **수주의뢰 매칭** | 거래 분쟁/검수·에스크로·정산·결제수단·법적/플랫폼 분리 모델을 검증한 뒤 별도 사업 결정. ‘5% 수수료’는 아이디어일 뿐 확정 가격 아님 |
| P4 | **맥콩 교육 굿즈** | 캐릭터 원본/상업적 권리 증빙, 생산 단가·재고/반품·표시 의무 등 별도 사업성 검증 |

**버튼은 기능이 작동할 때만 연결한다.** 사용자가 “미리 준비해 둘 공간”과 “지금 바로 쓸 수 있는 기능”을 혼동하지 않게 함. 미래 기능은 맨 아래 소규모 ‘예정’ 소개만 허용하며 쇼핑/가입 UI는 미노출.

## 4. 개발 게이트 / 일정
- 14일 SELF MVP: **2026-10-25 ~ 2026-11-07**, 기능 확장으로 일정 자동연장 금지.
- 1차에서는 디자인 이미지(컨셉 목업)는 데모·실화면·실기능으로 표기하지 않음. 맥콩 공식 실사용 이미지는 별도 자산/권리 검토 후.
- 사이트 공개 전 점검표: (a) 유료 소스 무료 유출 여부 (b) 결제 버튼·외부 유도·URL 경로 (c) 과장 기능·허위 실적 (d) 무료 시연과 유료 기능 구분 (e) 반응형/UI 접근성/브라우저 QA.
- 이 문서는 기능 우선순위와 UI 정책 기록이며 Cloudflare/크몽/회원/결제 API 실행을 승인하지 않음.
