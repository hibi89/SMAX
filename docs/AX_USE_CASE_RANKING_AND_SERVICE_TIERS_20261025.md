# SMAX 자동화 사례 우선순위 + 셀프/설정 지원 2트랙 (2026-10-25 KST)

> **결정/미결정 구분:** 창업자 신규 방향 확정 = 업종을 가로지르는 대표적 업무 자동화 요청을 시장 조사에서 수요가 높은 순으로 SMAX 템플릿에 **한 개씩 누적**, 사장님이 AI+설계 문서로 **직접 구축 가능하게 안내**. '설정까지 해줘' 고객에게 **별도 유료 설정 지원 가능성**을 검토. **실 판매 가격·지원 범위·출시 일정·시장 수요 실제 1위부터 N위는 미확정.** 현재 매출/고객/서비스 운영 없음.

## 1. 핵심 모델: 2종 고객, 하나의 지식/템플릿 라이브러리
- **A. SMAX Self (프로그램):** 로컬에 업무 설명/공인된 샘플·CSV/XLSX 등을 넣음 → 지원된 업무 유형/데이터 스키마·규칙/불확실 사항·요구권한·누락 질문 → `AX_BLUEPRINT.json`, `DATA_SCHEMA.json`, `AI_BUILD_PROMPT.md`, `VALIDATION_CHECKLIST.md` → 외부 AI에서 사용자가 직접 단계별 구축. SMAX 자체 필수 외부 LLM API 호출 없음. 외부 AI/자동화 도구의 비용·연동 제한은 고객 부담/고지.
- **B. SMAX Setup (설정·구축 지원):** 동일한 SMAX 셀프 프로그램 출력/템플릿을 토대로 고객이 요청한 **한정된 표준 워크플로 1건**을 고객 계정에 원격으로 설정하거나 화면 공유로 같이 실행, 샘플 테스트/사용법/인수인계. 별도 가격·계약·납품/수정 범위. *상품 업셀링*이지 무제한 맞춤 SI가 아님.
- **코어 모델 유지:** 사업의 반복성은 셀프용 라이브러리·공통 템플릿 확충에 있고, 설정 지원은 시간을 소비하므로 수량/월 작업시간/고객별 지원시간 상한을 적용. 첫 14일 개발에 실제 고객용 별도 프로젝트/대리 구축 수임·완료를 추가하지 않음.
- **무료 보수** 사용자의 기존 방향과 충돌 방지: SMAX 프로그램의 **합의한 범위 내 오류 패치 및 공통 업데이트**는 무료 정책 후보. 새로운 사용자별 워크플로 설계·계정 연동·외부 API 설정·맞춤 요구 등은 별도 유료 설정 작업. 법정 하자 책임/고지와 명시한 보증 조건을 임의 축소하지 않음.
- 원격 설정이라고 해도 **고객이 로그인·API 키·MFA를 직접 입력하고 최소 권한만 승인**, 비밀/고객정보 수신 불필요한 합성 샘플 테스트를 우선. 고객 개인정보 취급이 발생하면 법률상 위탁 여부·계약·삭제·권한 회수·기록 등 판단 필요. 영업상 기밀을 AI에게 무단 업로드 금지.

## 2. 출시 우선순위 결정 방식
**통계적 수요 전국 순위는 아직 알 수 없다.** 순위 표시는 **전국 고객 니즈 순위가 아닌 '시장 검증을 먼저 할 내부 후보 순서'**로만 사용한다.
후보:
1. 이메일/첨부 Excel → 열 매핑/중복 검증 → 로컬/클라우드 폴더 저장 설계 (고객 이메일·계정 연동은 실제 Setup에서만).
2. 발주·주문·재고·판매 파일 정리 및 이상 감지.
3. 문의·예약·고객 요청 수집 및 확인/담당자 전달(외부 발신 승인 필수).
4. 정기 통계·영업 보고서 집계/생성.
5. 사내 문서/내규 RAG 요구 → 문서 형식·버전·접근제어/검색·근거·LLM 의존성을 반영한 설계 및 빌드 프롬프트. RAG 서비스 실제 완성은 AI/임베딩·호스팅·보안·모델 유지비를 따로 검토하므로 고난도.
향후 업종별 추가로 확장하되 새 업무 유형마다 질문 템플릿, 예외/권한 매트릭스, 샘플 정답, 검증 케이스를 별도 점검. '모든 사장님 공통 최다 수요' 주장 금지.
- **시장 검증 스코어** 후보별 0-5 점: 고객 **발주/요청 원문 건수**(우선), 실제 구매 가격/리뷰/거래 징후, 반복 빈도/절감 시간, 템플릿 재사용 가능성, 설치/지원 난도 역점수, 개인정보·운영 위험 역점수. 단순 검색 노출/판매자 상품 수는 수요가 아님.
- 최소 30~50개 관련 **구매자 요청 표본**과 별도 **판매자 경쟁/가격 사례**를 구분 표본화하고, 중복·업종/기업 규모·비용/기간·변경요구 표시 후 순위 갱신. 사용자의 '1위부터 추가'는 이 방법으로 검증된 순서. 검증 전에 1위라고 마케팅 금지.
- 지원 가능한 최소 공통 코어(종류별 완전 자동 완성 보장 아님): intake → 분류 후보 → 누락 질문 → 입력/트리거/변환/출력/권한/예외 표준화 → AI 프롬프트와 단계별 테스트 → 결과 내보내기.

## 4. 사용자 제공 상품 정책 제안(미승인)
- 제품 가격: **소액 연간 사용권 방향만 승인, 구체 금액 미정**.
- 구축 지원 서비스: 최초에는 **정해진 업무 유형·워크플로 1개·지원 앱 최대 2~3개·원격 1회·수정 1회·합성 데이터 검증·인수인계 문서**처럼 경계를 견적에 명시. 계정/키 입력은 고객 직접, 추가 서버/API/타사 앱 요금 별도.
- 검토용 **가격 가설**: 설정 도움 99,000~199,000원 / 표준 업무 흐름 1건 구축 199,000~399,000원. 경쟁 공개 호가와 고객 실제 지불 의사/작업시간/수수료 검증 전 확정 금지.
- 영업 체계: 크몽/기타 마켓을 통해 표준 자기구축 상품과 설치 패키지를 분리 게시할 수 있는지 카테고리·형태별 심사를 받음. 플랫폼을 통한 고객은 결제·추가 서비스도 **플랫폼 내 정식 견적/안전결제**, 홈페이지의 독립 방문/별도 유입과 섞어 우회 유도 금지.
- **스코프 제외:** ERP 내부 개발/실계좌 이체/대량 광고발송/고객정보 무단 클라우드 전송/검증 안 된 RAG 직원권한 보장/복잡한 장기 운영과 24시간 SLA. 개별 기업 특수요구는 거절하거나 별개 사업으로 분리, SMAX 무제한 서비스로 흡수하지 않음.
- 지속 가능성 판단: 1건마다 실제 개발/연락/수정/장애 대응 시간이 길어지면 '보조 수익'이 아니라 본업을 방해하는 외주일이 된다. 제품 판매, 설치 매출, 유료 전환, 지원시간과 순수익을 **분리 계측**.

## 5. 개발 일자와 역할
- `backend`: 고객별 구체 n8n 플로우 구현이 아니라 **설계 템플릿·분류 룰·누락질문·정형 산출물 생성기**를 구현.
- `frontend`: 셀프용 UI에 **직접 구축 / 설정 지원 별도 문의** 같은 경로를 디자인하되 실제 문의/결제 버튼은 사용자가 승인한 판매처가 열리고 정책이 확인된 뒤 노출. AX 연구소 쇼룸 운영은 Cloudflare 정적 호스팅.
- 전체 코드 실제 착수일부터 **달력 14일 상한 유지**. 구상·외부 조사·기획 문서 변경이 유료 서비스 출시나 코드 완성을 뜻하지 않음.

## 6. 2026-10-25 창업자 확정 운영 원칙 — 구축 불가 시 환불
- **창업자 지시:** 본인은 고객별 실구축 경험이 아직 없고 기술적 실패가 있을 수 있음을 인정한다. 별도 유료 'SMAX Setup'을 약정한 범위·완료 테스트 기준대로 구축하지 못하면 **해당 구축 지원비를 100% 환불**한다. 성능 및 구축 성공을 미리 보증/과장하지 않고, 작업 시작 전에 성공 정의와 불가 시 환불 방침을 고객에게 서면 고지한다.
- **구축 착수 전 기술 적합성 검사:** 요청 내용, 입력·출력, 대상 앱/계정, 접근 권한, 테스트 데이터, 고객 PC·유료 API·라이선스 요구, 성공/중단 조건, 예상 소요/테스트 시점을 합의. 불가능하거나 고위험한 요청은 계약 전 거절/범위 조정. 준비되지 않은 RAG·복잡한 ERP 통합 수임 금지.
- **성공의 객관적 판정:** 예: '지정 발신자 이메일 첨부 XLSX → 표준 열 파싱/중복 처리 → 고객 지정 위치에 누락 없는 저장'을 합성 테스트 케이스로 확인, 고객이 실제 연결·접근권한을 확인하고 최종 인수. 원인 모를 부분작동/데모 화면만으로 완료 처리하지 않는다.
- **환불 구분:** 약정 결과물의 구축 실패(공급자 사유) → SMAX 구축료 전액 환불. 애초 계약 시작 전 불가 판정 → 수주 거절/결제 취소. 고객의 중간 요구 추가·자료/권한 미제공·단순변심은 '기술적 구축 실패'와 구분해 플랫폼 규정·법률 및 사전 합의를 우선 적용. 고객 책임이라고 추정해 무조건 환불 거절하지 않음.
- **외부 비용:** 고객이 직접 결제하는 외부 AI/API/앱 구독료·계정 유지비 등은 SMAX의 구축료와 명시적으로 분리하고 발생 전에 고객 승인. 공급자가 고객을 대신해 집행하는 유료 비용은 아예 초기 서비스 범위에서 제외하는 방향. 이미 발생한 제3자 비용의 환불 가능 여부를 SMAX가 보장하지 않는다. 불필요한 외부 지출 없이 합성/무료 테스트 먼저.
- **거래 정책:** 크몽 등에서 계약한 건은 그 플랫폼의 구매자보호·환불/분쟁 처리 절차를 사용하고 별도 '전액 환불' 약속과 충돌·오해가 없는지 판매 전 확인. 크몽 품질보장 안내는 작업 요건·견적·최종 산출물·중간 의사소통을 기록하도록 강조. https://support.kmong.com/hc/ko/articles/50560780476953
- **자가 설치 프로그램과 분리:** SMAX Self 라이선스/다운로드 제품의 환불 기준은 구축서비스와 별도 정립해야 하며 '구축 실패시 환불'을 프로그램 상품의 모든 이용 실패에 자동 확대하지 않는다. 법적 청약철회·불완전 이행 책임과 플랫폼 기준은 최종 판매문안 수립 시 검토.
- **실행 상태:** 환불 결제/고객 계약/상품 등록은 아직 없으며 여기서는 창업자 결정 사항을 문서화할 뿐이다. 14일 개발 상한에 실고객 구축지원까지 추가하는 의미가 아니다.
