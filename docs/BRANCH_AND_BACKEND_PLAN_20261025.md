## 공식 홈페이지 인프라 — Cloudflare 선택
- Cloudflare의 **정적 사이트 호스팅**을 사용하기로 사용자 선택. 실제 사이트 코드/프로젝트 연결/배포는 별도 승인을 받으며, **현재 Cloudflare 계정·프로젝트 존재·권한은 미검증**.
- 공식 문서: Workers Static Assets <https://developers.cloudflare.com/workers/static-assets/billing-and-limitations/> — 정적 파일 요청 무료/무제한. Worker 함수를 호출하면 별도 Free 일일 한도/과금 정책이 적용됨.
- Cloudflare Pages도 GitHub 연결 가능 <https://developers.cloudflare.com/pages/configuration/git-integration/>; Cloudflare 권장 최신 신규 앱 기본은 Workers Static Assets. 실제 배포시 `site/` 빌드 산출물만 노출.
- 구매·라이선스 계약/거래·문의 이메일은 **외부 플랫폼/사용자 승인 연락처**로 관리. 정적 홈페이지에 별도 고객 DB/API/개인정보 폼을 신설하지 않음. 도메인 구매·실계정 연결·게시 전 사용자 승인 및 상표 검토.
