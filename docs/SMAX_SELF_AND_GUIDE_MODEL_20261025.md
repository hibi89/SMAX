# SMAX SELF 5만 원 + GUIDE 5만 원 — 창업자 최신 사업 모델 (2026-10-25 KST)

> **상태:** 사용자 신규 방향·가격 희망·불개입 원칙은 강한 창업자 의사. 실제 상품 카테고리, 판매 문구, 라이선스 기간, 강의 지원 기간/질문 상한/환불 문안·플랫폼 등록 및 법적 요건은 출시 전 확인. 제품·구축·판매/결제/문의 응대는 아직 없음.
> **우선순위:** 같은 날짜의 'SMAX Setup/원격 대행 + 구축 실패 시 전액 환불' 구상보다 **이 문서의 새로운 '구축 대행 없음, 질문 안내만' 의사결정이 우선**. 과거 문서는 경위로 보존.

## 1. 목표 시장 / 고객 경험
- AX 접근성이 낮은 소상공인·사장님이 **본인의 자료와 업무 흐름을 자기 PC에서 스스로 입력·구조화·검수**한다.
- SMAX 로컬 프로그램은 지원 범위 안에서 구조화 업무 모델, 불확실성 확인 질문, AI 인계 파일, 유형별 자동화 단계 안내, 검증 체크리스트를 생성한다.
- 사용자가 자신의 AI/도구(ChatGPT, Gemini, Claude, n8n, Google Sheets 등)에 직접 입력·연동하고, 스텝 바이 스텝으로 따라가며 업무 AX/자동화를 학습한다. 'AI에 자료 첨부'는 고객 책임하에 기밀·개인정보·계약상 제3자 전송 가능 여부 확인 후 결정. SMAX 자체 외부 LLM API 호출은 필수가 아니다.
- **사장님 자신이 방법을 배워 향후 다른 업무도 확장한다**는 것이 핵심 가치. 사용자 노동/대행을 줄이는 것은 창업자의 명시적 운영 제약과 일치한다.

## 2. 상품 구성 / 가격
| 상품 | 창업자 제시 소비자가 | 제공물 | 제공하지 않는 것 |
|---|---:|---|---|
| **SMAX SELF** (코어 상품) | **50,000원** | 고객 PC 로컬 AX 자료/업무 표준화, 자동화 설계도·AI 구축 프롬프트·자가 검증표, 매뉴얼/일반 기능 오류 수정 | 고객 회사 원본자료를 판매자가 받아 재정리, 고객 계정 로그인·실연동·업무 실구축, 무제한 개인 코칭 |
| **SMAX GUIDE** (별도 구매 추가 옵션) | **+50,000원** | 고객이 **직접 구축하다 막힌 단계**에 대한 비동기 문자·익명화 화면·가상 오류 로그 기반 진단, 재현/수정/다음 테스트 안내. 교육·코칭이며 성공보장 구축계약 아님 | 전화·화상·현장방문·원격 PC 조종·로그인 대행·고객 회사 데이터/기밀 수집·임의 개발·유료 API 대납·무제한 상담 |
| **둘 다 구매** | **100,000원** | 위 범위 합계 | 장기 운영 책임·고객별 자동화 구축 납품 보장 아님 |

- 위 가격은 **창업자 희망판매가로 기록**, 판매 승인/크몽 실제 등록 가격/세후 수익 확정은 별개. 마켓 수수료, 정산, 세금, 환불 반영한 기여이익을 출시 전에 검증.
- 과거 '저가 연간 사용권' 방향은 역사적 배경이며 **현재 5만 원이 1회/1년 갱신 중 어느 방식인지 미확정**. 고객에게 임의로 연간 요금이나 자동갱신을 약속하지 않는다.
- SMAX GUIDE는 SELF의 모든 기능을 포함하는 상위 SW 등급이라기보다 **명시된 횟수/기간의 1:1 문자 학습 지원을 별도로 구매**하는 서비스. 가이드 미구매도 SELF 독립 가동에 지장 없어야 한다.
- 사용 중 발견한 **공통 SW 버그 수정/표준 설명서·템플릿 개선**은 무료 보수 방향. 미구매 고객에 대한 개별 문제 해결 약속이나 고객의 시스템 설정 대행은 포함하지 않는다.

## 3. GUIDE 운영 상한 — 출시 전 검증이 필요한 '총괄 제안'
- 지원 창구: 구매 플랫폼 공식 메시지(예: 크몽 채팅)에서만 진행, 별도 전화번호/개인 카카오톡/회의 링크/원격접속 제공하지 않는다.
- 한 개의 SMAX가 생성한 **업무 자동화 목표/설계도 1건**을 지원 대상으로 제한.
- **예시 제한:** 구매일 또는 지원개시일부터 **7일**, '독립 오류/막힘 문의' **최대 3건**(각 건의 관련 후속 질의 포함), 답변은 **영업일 기준 1~2일 내 목표**, 연장·추가 문의는 자동 무료 제공하지 않음. *모두 창업자 최종 결정과 마켓 정책 확인 전 미승인 초안*.
- 구조화된 질문 템플릿: [1] SMAX 템플릿/가이드 단계 번호 [2] 사용 도구·버전·지원 OS [3] 기대 출력 [4] 현재 출력·**가림 처리한** 오류 텍스트·화면 [5] 본인이 이미 시험한 작업 [6] 합성 입력·샘플. 계정 비밀번호·API 토큰·실고객 PII·실거래 내역 업로드 금지.
- 답변 템플릿: [원인 가능성 분리 → 고객이 직접 할 조치 1~3개 → 기대 결과/확인법 → 실패 시 요청할 추가 비밀 없는 정보 → 안전한 중지 조건].
- 기존 고객별 고장/비정형 툴에 대한 재현·개발 시간이 **지원 수익을 넘는 경우** 사전 상품 제외 조건에 따라 가능한 범위/일반 해법/타 지원 경로를 고지. 결과물 완성을 보장하지 않으며, 실제 제공한 가이드의 약정 이행 여부를 별도로 확인.
- 참고할 시장 사례(공개 판매 **제시가격**, 거래량/실적 증거 아님): https://kmong.com/gig/761266 는 AI 자동화 교육과 별도 1:1 문자 채팅 피드백 패키지를 구분. 판매자 제시 가격 98,000/300,000/1,000,000원(조회 시점); 사용자 5만 원 요금의 수익성을 보장하지 않는다.

## 4. 환불·품질 책임에서 구형 모델과 구분
- **'구축 실패 시 100% 환불'은 이전에 상정했던 '판매자가 실제 고객 자동화를 설치·완성하는 SMAX Setup' 계약을 전제로 했다.** 해당 직접 대행 상품은 **현재 우선 출시 범위에서 제외/보류**. 전액 환불 문구를 'SMAX GUIDE가 고객의 모든 자동화 성공을 보장'으로 옮기지 않는다.
- GUIDE 판매 시에는 **지원 제공 범위·기간·문의 횟수·미지원 케이스·미이행/중단 기준과 환불 조건**을 사전 고지하며, 서비스 미제공이나 약정 불이행 시 플랫폼/법령에 맞는 적절한 환불·취소 절차를 제공한다. 단지 고객 본인이 끝내 자동화를 완성하지 못했다는 사실만으로 무조건 100% 성공보증을 주장하지 않는다.
- 구매자 귀책 여부를 임의 단정하지 않고 고객 확인과 플랫폼 조정 규정을 준수. 고객의 선불 외부 구독료·API 비용은 고객이 직접 별도 승인/결제, SMAX가 그 환불까지 보증하지 않는다.
- 크몽 유입 고객의 거래·추가 옵션 결제/환불은 **크몽 내 절차와 정책** 사용. 외부 개인 계좌·홈페이지로 유도 금지.

## 5. 데이터 보안 절연
- **데이터 본체를 보지 않음**: 회사 자료, 실제 내규·고객명·거래 자료·식별정보, 계정 인증정보를 판매자가 수집하지 않고, 자료 정리도 고객 PC/고객 AI 서비스 선택 영역으로 유지.
- 무해화한 화면 캡처·오류 메시지조차 세션/계정 식별자, URL 쿼리, 시트 내용, 토큰이 실수로 포함될 수 있으므로 안내문에 가림·검수 체크리스트와 **실제 정보 대신 합성 테스트로 재현**하는 방법을 제공.
- 외부 AI에 파일 전달시 개인/비밀 자료는 해당 공급자의 정책과 회사 내부 허가/익명화 여부를 확인하도록 프로그램에서 사전 주의 표시. 가명처리 자체가 모든 공유의 법적 문제를 자동 해결하지 않음.

## 6. 팀/개발에 반영할 것
- `backend`: 첫 14달력일 내 기본 코어: 로컬 분류→표준 데이터/설계도→AI 구현 명령→단계별 검증과 '자주 막히는 문제' 가이드 생성. 실제 자동화 구현/고객 계정 연동 엔진을 무리하게 추가하지 않는다.
- `frontend`: 쉽게 따라 하는 사용자 UX, FAQ·'막힌 단계 복사'·정보 가림 예시·지원 옵션 설명. 외부 사이트는 Cloudflare 정적 AX 연구소 쇼룸, 고객 자료를 수신하는 온라인 질문폼 구축 금지(필요시 추후 검토).
- **명확히 분리:** 기본 SW 오류/약속한 기능 자체가 작동하지 않을 때는 제품 품질 이슈로 무료 지원; 고객의 개별 외부 도구 연결/설정 학습 지도는 GUIDE 범주. 사용자에게 숨은 추가비용으로 오해시키지 않는다.
- 실거래/서비스/고객/AI 과금/Cloudflare 배포/프로덕션 테스트 **미착수**. 14일 총개발 상한 변경 없음.
