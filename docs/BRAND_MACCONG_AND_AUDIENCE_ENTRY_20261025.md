# SMAX² Square — 맥콩 공식 캐릭터 및 이용 목적별 광장 설계
기록일: 2026-10-25 KST · 상태: 창업자 결정 / 브랜드 기획 고정 / 대외 출시 미승인

## 1. 이름과 철학
- 브랜드 표시: **SMAX²**, 설명형 브랜드명 **SMAX Square / 스맥스스퀘어** (법적 상표검증 전 가칭).
- Square는 **누구나 모이고 참여·공유하는 광장**이라는 핵심 뜻이 있으며, 위첨자 ²는 **아이디어/업무 자동화 템플릿의 공유·재사용·확산·가속**을 함께 상징한다. 반드시 "Multiplied"라고 풀어 쓰는 브랜드가 아니다.
- 브랜드 문구: **혼자 시작하고, 함께 발전하는 AX 광장.**

## 2. 캐릭터 공식 선정: 맥콩
- 창업자가 제시한 **스돌이 / 맥콩 / 셀리** 중 내부 공식 마스코트명 **맥콩**을 선택·확정. 이름의 상표/저작권 가능 여부는 별도 검증.
- 기준 시각 자료는 **현재 대화에서 사용자가 올린 로봇 스크린샷**이다. 과거 다른 로봇의 이미지나 임의 검색 일러스트로 변경하지 않는다.
- 특징: **두 장의 연두색 새싹**, 부드러운 **흰색·연보라색 둥근 사각형 로봇**, 얼굴의 **밝은 청록색 테두리**, 동그랗고 큰 **보라빛 눈**과 작게 웃는 입, **연보라·보라색 귀/헤드폰 패드**, 친근한 3D 토이 스타일. 학생·사장님 모두에게 편안한 톤.
- 역할: 사장님 템플릿 입문·가이드, 추후 학생 AI 교육의 안내 친구. 실제 AI 모델 추론이 내장된 봇으로 오해시키지 않는다.
- 맥콩의 성격: 친절하고 쉬운 설명, 과도한 의인화나 '모든 자동화가 완성된다'고 과장하는 대사 금지.
- 표정/응용 동작: 인사, 설명, 생각, 성공, 도움 요청. 얼굴·새싹·귀패드의 형태를 모든 장면에서 일관되게 유지.
- **아직 상업용 투명 배경 원본, SVG, 3D 모델, 상표/캐릭터 권리 입증용 파일은 저장소에 없음.** 대화 스크린샷은 디자인 레퍼런스이며 홈페이지에 자동 게시하지 않는다.
- 이전에 생성한 홈페이지 디자인 시안은 **그대로 보존**.

## 3. 홈페이지 최초 진입 UX: 목적별 광장
- 첫 방문자에게 **"어떤 목적으로 오셨나요?"** 안내. 두 선택 카드:
  1. **사장님용 — 사장님 광장**: 기존 SELF 템플릿 10종, 스마트 검색, 안내형 챗봇 패널, 데이터 표준화·AI 구축 문서, 사례·커뮤니티. **첫 출시 대상**.
  2. **학생·학부모용 — 배움의 광장**: 맥콩과 함께 AI 기초 원리, 영상·연령별 커리큘럼, 만들기 미션과 안전한 학습. **장기 개발, 현재 준비 중** 표시; 실제 기능 없이 로그인·결제 유도 금지.
- 공통 헤더로 SMAX² 브랜드, 맥콩, 공통 광장/소개 영역을 유지. 사장님은 1~2회 클릭으로 바로 현재 템플릿 기능에 접근. 강제 가입 팝업 없이 둘러보기 허용.
- 현재 첫 출시에서 **사이트 회원가입은 구축하지 않는다**. SELF는 로컬 오프라인/크몽 유통 우선, 유료 WEB 접근권한은 2차 별도 개발.
- 향후 회원가입을 도입할 경우 회원이 선택할 수 있는 *관심 목적/콘텐츠*를 `business`, `learning`(또는 복수 선택)으로 분류하되 실제 법적 신분/나이를 이 필드 하나로 검증했다고 주장하지 않는다. 사장님과 학생을 강제 배타적으로 분리하지 않는다.
- 학생·아동 관련 데이터 수집은 나이·보호자 동의·개인정보 최소수집·보관/삭제 규칙을 적용 가능한 법령과 서비스 범위로 별도 검토·설계. **학생 서비스 출시/가입 시스템/정부사업 협약은 미착수**.

## 4. 구현 및 출시 우선순위
- 현재 D1 코드 개발 시작일 **2026-10-25**, 14달력일 마지막 **2026-11-07**.
- **최우선 작업은 사장님 SELF 유효 기능, 로컬 완성형 1~2개 후보의 실작동, 무료/유료 번들 분리, 검증**. 학생용 교육·회원가입·커뮤니티 회원 DB·WEB 유료 서버를 끼워 넣어 14일 범위를 확대하지 않는다.
- 프론트에 목적별 입구를 선반영하는 경우에도 학생 카드에는 '준비 중' 표시, 클릭 시 설명만 볼 수 있도록 구현. 실제 성인 구매/어린이 회원가입 가능하다는 오해 방지.
- 확장: (1) SELF 사장님 광장 (2) 유료 웹 완성형 WEB 별도 (3) 학생·학부모 AI 교육 프로그램 (4) 교육기관/공공 협력은 향후 검증·사업제안 단계.
- 새 결정은 **디자인·상품 전략/문서만 갱신**, Cloudflare 사이트 배포·상품 등록·캐릭터 권리 등록/라이선스 취득을 실행한 것이 아님.
