# SMAX 수익화·유통 가설 (2026-10-25)

## 원칙
- 사용자는 기업 방문, 콜드콜, 전화 중심 영업, 맞춤형 외주 수주를 지향하지 않음. **온라인 검색→자가 체험→셀프 구매/설치**와 별도 파트너 판매가 핵심.
- 비용의 기준은 '고가 외주 금액 전체'가 아니라 그중 반복적·표준화 가능한 업무의 고객 가치.
- 단순 AI 기능 3개를 묶는 게 아니라 입력→검증→승인→출력까지 **하나의 실제 업무**를 연결하는 상품.
- 기존 저가 SaaS가 있는 이유/한계: 업무규칙 특수성, 기존 시스템, 지저분한 파일, 고객 설정 역량, 운영 책임, 보안. SMAX는 모든 문제를 해결하겠다고 약속하지 않는다.

## 가격 가설 (출시 가격 미확정)

> 99,000원, 월 99,000원, 연 990,000원은 지금의 **가격 테스트 가설**. 지불의사·시장가격·수익성이 검증되지 않음. Partner 가격도 초기 고객수 제한과 단가 실험 필요.

## 타깃/진입 순서
1. 반복적인 파일·데이터 정리와 간단한 판단이 필요한 한국 소기업/소상공인.
2. 다양한 사업자 대상 표준 업무 도입을 제공하는 IT 프리랜서·ERP 컨설턴트·소형 대행사.
3. 공개 사례·한국어 문서·CS 체계가 잡힌 뒤 해외 소규모 기업 대상 검토.

## 유통 채널
- **주력:** SMAX 공식 웹사이트 (데모, 계정 생성, 가격, 결제, 온라인 문서, 자동 발급).
- **유입:** 네이버/구글 문제별 검색 페이지, 샘플 데모, 비교 콘텐츠, 짧은 기능 영상.
- **보조:** 크몽에 정해진 표준 패키지형 상품을 등록할 수 있는지 약관/심사 확인. 위시켓을 SMAX 맞춤 외주 수주 채널로 강제하지 않음.
- **파트너:** 제휴 링크로 추천 수수료(예: 15~25% 시험)를 지급하는 affiliate → 고객별 라이선스와 정식 계약을 포함한 reseller.
- **해외:** AppSumo 등은 영어 지원·운영·수수료·환불 조건 충족 후 검토.
- 광고: 유료 구매 전환이 측정되기 전에는 0원 시작. 검색 노출도 콘텐츠 제작 시간이 필요한 작업.

## 복제·공유 방지 모델
**설치파일 영구 판매가 아닌 SaaS 계정/고객별 작업공간 라이선스**를 권장. tenant ID는 로그인 세션 서버에서 강제; API 요청만으로 다른 사업자 작업공간 접근 불가. 좌석/동시세션/월 사용량/크레딧/재판매 계약으로 비용을 통제. 100% 공유 방지는 불가능하므로 과잉 DRM 대신 합리적 권한·가격 전략.

## 첫 판매 퍼널
문제 해결형 랜딩 → 공개 샘플 데이터 무료 시연 → 정확도/규칙 누락 공개 → 고객 본인 자료로 제한 체험(보안/처리 안내 후) → Solo 구매 → 반복 사용 발생 시 Business → 파트너 채널.
고객 10명 인터뷰·3명 유료 파일럿 의향은 **검증 목표**이지 이미 확보한 고객수가 아님.

## 측정 지표
유입, 체험 시작률, 체험 완료률, 유료 전환율, 환불률, 활성 워크플로, 업무설정 소요시간, 워크플로 성공률, 모델 비용/고객, 월 고객 이탈률, 반복 매출(ARR), 파트너별 활성 고객 수.

## 장기 엑싯 가설
50~100억 기업가치는 **장기 상상/목표 시나리오**이며 현재 인정된 가치나 투자 제안이 아님. 향후 분할매각/전량매각/전문경영 체제는 실재 매출·유지율·세후 거래조건에 따라 선택. ARR 배수와 고객 수 계산은 단순 시뮬레이션이지 확정 valuation이 아님.

## 2026-10-25 창업자 수정 방향 — 연간 맛보기·온라인 단골

- **판매의 중심:** 자금·기술·인력이 부족한 소기업 사장님에게 표준 AX 준비를 직접 해볼 수 있는 저가의 **연간 사용 경험** 제공. 대기업 SI/맞춤 AX 개발은 의도적 제외.
- **연간 가격은 아직 미정.** 위 Solo 일회성/Business 월/Partner 연 가격표는 역사적 가설로 보존하되 정식 현재 상품 가격으로 인용 금지. 별도의 작은 연간 사용권(SMAX Year/Starter 등 가칭)을 우선 시험하는 **전략 방향**을 기준으로 차기 요금표 재설계.
- 1년 동안 받을 구체적 가치가 없으면 연간 선결제 장벽이 될 수 있으므로 **무료 합성 데모·짧은 체험·환불 기준·비자동 갱신 또는 명확한 갱신 동의**를 비교하여 결정한다. 실제 고객 데이터를 써야 하는 체험은 데이터처리 계약/동의 이후에만 가능.
- **원가 제한은 필수:** 고객마다 자체 워크스페이스/사업자별 데이터 분리, AI 토큰·파일·용량·실행량 상한, 자동 초과요금 금지, 연간 환불/갱신·CS 비용을 함께 계측. 연간권=무제한 AI 실행 아님.
- **온라인 로컬 단골집 콘셉트:** 지역 방문 영업이 아니라 작은 사업자 커뮤니티·검색·사용자 추천·공유 가능한 **기밀 없는 결과 예시**·친숙하고 일관된 지원으로 신뢰를 쌓음. 입소문이 자동으로 발생한다고 가정하지 말 것.
- 진입 시점의 높은 시장 가격과 낮은 표준 공급원가의 차익은 **수익 가설**. 경쟁자가 쉽게 복제할 수 있어 영구적인 가격/점유율 우위는 예상하지 않음.
- 확장: 첫 상품이 작동하고 유료 갱신/추천이 관측된 후 연관 서비스/새 사업을 탐색. 후속 서비스의 개발·지출은 따로 승인.
- **제품에 관한 중요한 정정:** 발주서↔명세서 대사(B)는 기술 검증에 사용 가능한 단편적인 예제일 뿐, SMAX의 목표를 '명세서 검사 SaaS'로 축소하지 않는다. 범용 AX 준비 인프라와 업종을 가로지르는 공통 표준이 중심이다.

### 측정해야 할 퍼널 (모두 현재 미측정)
무료 합성 예시 방문 → 첫 업무/자료 정리 완료 → AX 준비 결과물 내보내기 → 연간 사용권 구매 → 30/90일 재방문 → 1년 갱신 → 타 사업자 추천. 예상 고객획득비·지원시간·환불·모델 비용을 포함한 기여이익 검증 전 낙관적 수익 주장 금지.
