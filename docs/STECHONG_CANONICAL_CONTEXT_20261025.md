최상위 사용자 지시: **"너는 스총이다 레포지토리보고 작업이어가셈"**
기록: 2026-10-25 KST / 역할·목표·과거 결정의 정본. 향후 결정은 날짜와 실제 원격 증거를 비교해 갱신한다.

- **스총** = SMAX² Square의 전담 총괄: 제품·사업 전략, 사장님 존 SELF 설계, 기술 구현/코드 검수, 프런트 품질, 안전·패키징·크몽 출시 준비, 맥콩 브랜드 반영. 이 역할을 맡은 GPT-6는 안전하게 직접 코드 수정·테스트·원격 커밋을 수행한다.
- **해총** = 별도 `hibi89/hackathon-command-center-2026` 통합총괄: KIC/PayPal/UGREEN 및 장기 해커톤 일정·진도·품질·외부 제출 위험 감독. 개별 대회 실개발은 각 `lead/*` 담당 총괄의 몫. **스총의 명령으로 해커톤 레포를 건드리지 않는다.**

- 스총 재시작 문장은 사용자 별도 설명 없이 곧바로 **이 Private repo `hibi89/SMAX`**를 읽어 복원하는 지시다. 단, 저장소 연결이 끊기면 추측해서 작업하지 않는다.

## 1. 핵심 미션·세계관
- 브랜드 **SMAX Square / 스맥스스퀘어**, 워드마크 **SMAX²**. Square는 **사람이 모이고 참여·공유하는 광장**, ²는 지식/AX 실행력의 확산·가속. 'SMAX Multiplied'라고 풀어 쓰지 않는다. 표어 **"혼자 시작하고, 함께 발전하는 AX 광장."**
- **핵심 취지: 염가로 AX의 대중화·접근성을 가속화**한다. 초보자·소상공인이 기술 장벽/비용 때문에 소외되지 않도록 하되, 운영이 불가능한 적자 판매를 무조건 약속하는 것은 아니다.
- 브랜드 공식 안내자 **맥콩** 확정(스돌이/셀리 대신). 창업자가 업로드한 원본 레퍼런스: 흰색·연보라 둥근 토이 로봇, 큰 보라 눈, 하늘색 얼굴 테두리, 보라 헤드폰, 초록 새싹 두 잎. 기존 생성 사이트 이미지 시안 보존. **깃허브에 상업용 캐릭터 원본 파일·상표권 검증 완료 증거는 아직 없음.**
- 사용자 잠시 언급한 2~3년 내 기업가치 50억~100억/엑싯은 **최신 사용자 결정으로 철회된 매각 목표**. 장기 성장 욕구는 남아 있으나 회사를 팔기보다 가격 접근성·참여 철학/운영 주도권을 유지한다. 50억~100억은 근거 있는 평가액이 아닌 가정.

## 2. 상품 비전 및 최신 승인된 범위
**1차(2026-10-25~11-07): 사장님 존 + SELF**
- 초기 10종의 **업무 구조화·교육·템플릿 설계 가이드**(10종 전체 실제 원클릭 자동화 완성형 아님).
- 템플릿 패널 + 규칙 기반 대화형 안내 패널(실 LLM 챗봇 아님); 한국어 동의어/유사 업무 검색; 템플릿 정의와 필요 데이터 필드/확인 질문/예외 표시.
- 고객 CSV/XLSX의 업무 맥락별 표준화 지향; 현재 코드는 **CSV 열 구조 읽기/매핑 후보/확인 + AX 설계 JSON·외부 AI 구축 가이드 Markdown 생성** 정도. 실제 사용 가능한 **로컬 CSV 변환 결과물 최소 1종**, 가능하면 매출 보고 1종을 더 구현해 **직접 회귀 테스트**로 증명한다. XLSX 직접 파싱·Windows 설치형 패키지는 아직 미검증.
- 고객 자신의 PC에서 처리, 필요시 자신이 고른 ChatGPT/Gemini/n8n/Sheets에서 안내대로 직접 구축. **외부 고객 메일/Gmail/ERP/RAG와 자동 통합, AI 자동 상담, 무제한 업무 실행을 약속하지 않는다**.
- SELF 제안 희망가 **₩50,000 (가설)**. GUIDE는 제한된 **비동기 문자 학습 지원 +₩50,000 (가설)**, 원격 구축 대행·실데이터/계정 접속·전화 서비스 아님. 실제 상품등록/지급/판매/환불 범위는 미확정.
- 공개 홈페이지는 **사장님 존 중심의 무료 안내·정확한 미리보기**. 메뉴 '템플릿/이용 방법/광장 소개/상품 안내'. **별도 사이트 결제·로그인·장바구니/수주의뢰 거래 금지**, 크몽 실제 상품 등록 뒤 조건에 맞게 안전결제 안내. 크몽에서 외부 거래로 유도 금지. 크몽 상품페이지 외부 링크 가능 여부 검토 전 삽입하지 않음.
- 사이트 `site/app.mjs`/`site/core.mjs`에는 유료 상품과 유사한 생성 기능이 섞여 있어 **그대로 Cloudflare 공개하면 코어 무상 이용/복제 위험**. 정적 데모/유료 SELF 패키지 분리 전 공개 배포 금지. Cloudflare 기술방향은 선택됐지만 계정/URL/정식 배포 아직 없음.
- 제품 개발 달력 14일 **2026-10-25 착수 ~ 2026-11-07 상한**, 자동 기간 연장이나 상용 판매 판정 금지.

**2차 별도 승인 이후: WEB**
- 특정 템플릿에 대해 입력→업무 처리→결과다운로드가 **실제로 끝나는 웹 도구**를 제공. 원칙적으로 결제된 templateId/계정만 서버에서 승인. URL 비밀 처리나 클라이언트 잠금만으로 접근 제어 불가. 서버측 entitlement/인증/비용/데이터/결제정책은 현재 **미구현·1차 제외**.
- 단순 CSV·매출 보고 등의 확실한 자동 처리부터. Gmail/OAuth/RAG/ERP 등 사용 설정 없는 즉시 구동을 보장할 수 없음.

**장기 확장(미구현):**
- 학생·학부모 **배움의 광장**: 맥콩 AI 기초영상·저렴한 단계별 교육/미션. 미래 회원가입 시 `business`/`learning` 복수 관심사 지원 가능. 미성년자 보호자 동의/개인정보 설계/교육내용 검증 필수. 1차 홈페이지에서 학생 서비스/로그인·판매를 실제 존재처럼 표시 금지.
- **공백상권** 창업/입지 분석 도구 추천(별도 기존 제품을 연결), 참여형 신규 자동화 템플릿 제안·공유(실 DB/개인정보/운영정책 필요), 맥콩·NAON2 캐릭터/IP·문구 굿즈(권리와 운영 검토).
- **수주의뢰/개발자 매칭**과 '5% 수수료'는 장기 구상에 불과. 결제·정산·환불·분쟁/플랫폼 규정 검토 전 거래소 실행 금지.
- 향후 교육기관·정부사업/기업 제휴는 실제 교육 효과·기술 실적·제품 신뢰 근거를 축적한 뒤 추진. 진행 중인 제휴/출시 실적으로 주장하지 않는다.

## 6. 재개·기록 계약
- 정확한 호출 문구 `너는 스총이다 레포지토리보고 작업이어가셈`. 새 채팅에서 확인 질문을 되풀이하지 말고 저장소 최신HEAD와 이 문서, `CHAT_BOOTSTRAP.md`를 읽고 **안전한 미완료 작업 1개** 직접 수행.
- `ㄱ`은 스총 채팅에서 현재 승인된 안전한 다음 작업만 시행. 다중 채팅 동시 실행·백그라운드 워커 없음.
- 작업 종료 시 수정 파일·실행 테스트 숫자/명령·PASS/FAIL·합성/실외부 구분·잔여 작업·블로커·원격 SHA를 `STATUS.md`/`HANDOFF.md`에 기록. 다시 HEAD 읽어 실제 커밋 확인.
- **외부 승인 필요**(Cloudflare 공개, 크몽 실제 거래/상품게시, 고객 개인정보, 유료 API, 비용/도메인, 사업자 계약)은 중단점 명확히 적고 사용자에게 결정 요청.


## 최신 브랜드 선택 (2026-10-25, 상단 맥콩 설명을 대체함)
- 창업자가 **NAON2 = 나온이**로 표기를 직접 교정. NAONI/나오니 등의 가명 사용 금지.
- 홈페이지 시각 세계관은 **아날로그 나온이(기존 고양이·밀짚모자·파란 리본)** 및 **디지털 나온이(화이트/블루 로봇 고양이·네온 귀/눈·AI 장비)** **두 개 모두 채택**. 홈페이지의 맥콩은 제거 방향으로, 맥콩은 이전 디자인 기록으로 보존. 실제 사이트 적용 여부는 이미지 자산/코드 점검 필요.
- 로고 시각 기준은 **2026-10-25 두 번째 생성 3분할 그림의 가운데 작업실 장면, 노트북에 새겨진 금속성/은백색 SMAX²·푸른색 위첨자 ²·아래 SMAX SQUARE**. 이전 로고 스타일 미확정은 덮어씀.
- 공식 완전형 로고 문구 `SMAX²` / `SMAX SQUARE` / `함께 만드는 AX광장`, 작은 공간의 축약형은 노트북 같은 2줄 `SMAX²` / `SMAX SQUARE` 허용.
- 상세·이미지 근거 설명: `docs/NAON2_DUAL_FORM_AND_LOGO_DESIGN_DECISION_20261025.md`. 해당 생성 이미지 바이너리나 새 SVG 원본은 GitHub에 자동 저장되지 않았음. 이전 맥콩 브랜드 문서는 이력으로 보존하고 앞으로의 홈페이지 아트 디렉션은 본 최신 결정 우선.
