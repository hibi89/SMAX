## 0. 출시 상품과 최상위 요건
- 상품: **SMAX SELF (희망가 50,000원)** = 고객 PC 로컬 자료·업무 정리 → 지원된 10개 업무 유형 템플릿 → 표준화·업무 설계·누락질문 → **AI 빌드 프롬프트와 단계별 검증/교육 자료 생성**. 자기 AI에 붙여 직접 n8n/Sheets 등 도구 설정·시행.
- **SMAX GUIDE +50,000원** 선택형 제한된 **비동기 문자 튜터**, 직접 구축 대행·고객 파일 전달받기·원격 PC조작·전화·무제한 성공 보증 없음. 지원일수/질문상한/라이선스 기간은 아직 미결정.
- 범용 자연어 AI 이해·실제 Gmail/Google API 쓰기·RAG 완제품 구축·실제 자동 이메일 발송 등은 **v1.0 로컬 엔진에 내장되지 않음**. 고객이 선택한 외부 AI/자동화 도구에서 별도로 시도.
- 출시 10개는 **설계 템플릿+AI 가이드 제공 대상**이며 실제 외부 서비스 작동 자동화 10종을 뜻하지 않음. '실제 로컬 엔진 실행 확인' 1~2종 영상/합성 fixture로 증빙하는 것이 초기 우선.
- 사이트: Cloudflare 정적 AX Lab 쇼룸, **10개 자동화 사례 상세 카드/검증된 시연/업무 결과 예시/대중화 비전**, 비즈니스문의·고객 업로드·서버·회원가입 없음. 상품 등록 후 크몽 정식 구매 링크(구매 계약은 크몽). 실제 배포/가격 게시/상표·도메인 확인은 별도 승인.
- 확장: v1.0 **10개**, 이후 시장 수요 검증 순으로 **50 → 100 → 1,000개 목표**. 순위는 국내 전국 객관적 실수요 통계 확정치가 아니라 연구할 후보 순서. 숫자 확장 자체보다 **검증된 안내의 품질** 우선.

## 2. 기술 설계 (백엔드 작업의 중점)
- 기술 선택 **추천 TypeScript/JS 규칙 엔진** + 직접 데이터/파일 파싱 + 순수함수형 코어. Python 기존 P0 ZIP을 실제 검수한 뒤 필요한 아이디어만 합법적으로 이전. 구현 언어 확정은 P1에서 점검.
- 템플릿 데이터는 `{id,version,category,aliases,requiredInputs,fieldMap,questions,workflowSteps,tools,permissions,exceptions,validations,costWarnings,learningGuide}`처럼 **콘텐츠 + 계약 분리**. 템플릿 추가 때 핵심 엔진 코드 수정이 불필요해야 함(새 포맷/해석 기능 자체가 필요한 경우 엔진 변경 가능).
- Core API 예시: `listTemplates()`, `classifyCandidate(input)`, `inspectLocalFile(file)`, `askMissingQuestions(model)`, `buildAxBlueprint(model, answers)`, `exportAiHandoff(blueprint)`, `getTestChecklist(blueprint)`.
- 분류가 모호하면 임의 확신 금지/사용자 질문. 파일명/열만 보고 의미 단정 금지; 고객이 직접 구조와 기밀 전송을 승인. 자동 발신·ERP 쓰기·결제·무승인 인터넷 요청은 기본 코드에서 제외.
- 공개 홈페이지로 나가는 것은 **합성 fixture, 서술·이미지·검증된 데모 결과만**. PRIVATE 문서·소스 전체·제품 라이선스 데이터가 site bundle에 포함되지 않도록 분리.
- 고객의 실제 AI 사용량이나 n8n/Sheets 등 별도 서비스 요금은 SMAX 자체 비용과 다름.

## 7. 최신 아키텍처 의미 확인 — AI 없는 전문가 시스템
- 사용자 재확인: **SMAX 엔진 자체는 별도 AI/유료 LLM 없이 미리 저장된 업무 로직으로 작동**. '로직의 RAG화'는 지식을 모아 필요할 때 검색·조립한다는 비유이며, 기술적으로는 **규칙 기반 전문가 시스템 + 템플릿/결정표 라이브러리 + 스키마 정규화 파이프라인**. RAG의 '검색 증강 **생성**' (LLM 기반 답변 생성)과 동일시하지 않는다.
- v1.0 표준 구현은 사용자가 **업무 유형 선택 → 사전 정의된 질문 → CSV/XLSX 헤더/데이터 형식 검증 → 규칙 충돌/누락 질의 → AX 구조화 결과와 검증체크리스트 → 외부 AI에 전달할 구축 지침 출력**. 외부 AI 서비스는 고객이 **별도로 선택하고 사용**; 자체 제품의 기본 AI 호출 비용 0원.
- 임의 자유문장의 의미를 보편적으로 추론하는 기능은 지원 약속하지 않음. 분류가 모호하면 사용자가 유형을 선택하고 직접 확인한다. 템플릿 10→50→100→1000 증설은 **검증된 지식·튜토리얼의 수**를 늘리는 것. 새로운 외부 플랫폼의 인증·버전/권한·운영 리스크가 자동 해결되는 것이 아니다.
- 구현 언어는 Python 필수 아님. **TypeScript/JavaScript 순수함수형 로컬 코어 우선**; Python은 사전 P0 ZIP 검토 뒤 실익이 있으면 활용. 고객 PC Windows 오프라인 사용성과 로컬 UI 통합 비용을 우선.
