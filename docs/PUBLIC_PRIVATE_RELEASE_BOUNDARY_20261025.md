# 2026-10-25 SMAX² 공개 쇼룸 / 유료 SELF 배포 경계 (frontend)

## 목표와 결정
- 고객용 공개 사이트에는 **브랜드·템플릿 소개만 노출**하며 개인 PC 로컬 변환 엔진, 실제 파일 처리, 유료 설계서 생성 로직, 내부 사업 원본 자료를 포함하지 않는다.
- **안 A (채택):** `public-site/` 독립 정적 페이지, `site/` 기존 SELF 로컬 제품 소스 보존. `wrangler.jsonc`의 `assets.directory` 기본값을 `./public-site`로 변경. 파일 배포 목록을 눈으로 확인하기 쉽고, 별도 빌드 도구/유료 인프라가 없으며 실수로 코드가 배포되는 위험을 줄인다.
- **안 B (보류):** 하나의 `site/` 소스에서 실행 기능을 빌드 시 제거하여 무료 결과만 게시. 코어 누락 검증·번들러 유지보수·잘못된 번들로 유료 코드 노출 위험이 커서 14일 MVP에 불리하다.
- 웹에 공개되는 HTML/스타일은 복사 가능한 콘텐츠라는 한계를 인정한다. SELF 전용 엔진·실제 작동 코드는 **공개 경로 밖**에 둔다. Cloudflare에 Private 레포 연동을 하려면 서비스 제공자에게 소스 접근권을 부여하는 것이므로 실제 연결 전 별도 승인이 필요하다.

## 실제 수정
1. `public-site/index.html`: **무자바스크립트**·무로그인·무파일업로드·무결제·무외부연결의 한 페이지 쇼룸. 템플릿 10종은 설계 가이드로, 현재 실제 처리 후보 1종은 개발/검증 중으로 표시. 구매불가·크몽 상품 준비 중 명시. 공식 로고 `SMAX² / SMAX SQUARE / 함께 만드는 AX광장` 채택.
2. `wrangler.jsonc`: 기본 정적 배포 경로를 `./site`에서 `./public-site`로 변경. **실제 배포/연동은 미실행**.
3. `tests/public-boundary.test.mjs`: 공개 디렉터리 경계/허용된 정적 확장자/심볼릭 링크, API·JS·코어·업로드/결제 링크 무포함, 보안 선언, 브랜드/10종·미출시 상태, 내부 앵커 유효성을 검사하는 3개 Node 테스트.
4. `site/index.html`은 `main`의 공식 3줄 로고 HTML과 동일하도록 안전 교체했고 `site/styles.css`에 `main`의 로고 보조 CSS만 더해 기존 CSV UI 스타일 보존. `main`과 `backend`의 원격 소스는 수정하지 않음.

## 검증된 증거 및 한계
- `backend`의 기존 원격 Blob SHA와 동일한 로컬 Node 22.16.0 코어·테스트 파일을 실제 실행: `node --check` 2건 통과, `node --test tests/csv-transform.test.mjs` **10 PASS / 0 FAIL**.
- `frontend` 공개용 원격 `public-site/index.html`·`wrangler.jsonc`를 다시 조회해 **정적 코드 경계 11개 조건 PASS / 0 FAIL**. 실제 `npm test`에서 신규 테스트가 실행되었다는 의미는 **아님**.
- 이전 프론트 UI 가상 DOM 검증은 17 PASS/0 FAIL(별개 실행). 이번 작업에서 실제 Chromium·Windows·모바일·Cloudflare Production·구매 행위는 **미검증**.
- 공개 HTML의 CSP `frame-ancestors` 메타 지시는 브라우저에 의해 강제되지 않을 수 있으므로, 실제 호스팅 시 HTTP 응답 헤더 설정과 공개 리소스·네트워크/콘솔·모바일/접근성 검증 필요. 페이지에 현재 외부 스크립트·외부 폼은 없음.

## 차단/다음 단계
- 새 `public-site`는 의도적으로 고객 파일 처리·CSV 다운로드를 포함하지 않음. 실제 프로그램은 Private `site/` 기반 SELF 로컬 상품으로 **별도 패키징**해야 함. 다운로드 방식·사용권/업데이트·지원·환불 조건 미확정.
- 실 브라우저에서 `site/`의 파일 업로드→매핑→변환→미리보기→다운로드와 `public-site/` 소개 페이지를 구분 검수. Node 전체 `npm test`, Windows 로컬 전달 방식, 브랜치 통합 절차를 검증.
- `main`에 별도 브랜드 변경 커밋이 이미 있으므로 향후 병합 때 **fast-forward 불가/상호 변경 조정 필요**. 강제 업데이트 금지.
- Cloudflare 프로젝트·GitHub 연결·도메인·공개 배포·크몽 상품 게시·실결제는 사용자 별도 승인이 필요. 외부 API 호출·유료 지출 **0원**.
- 목표일 2026-11-07은 완료를 기다리는 날짜가 아닌 최종 상한이다. 검증 통과 시 조기 완료 가능.
