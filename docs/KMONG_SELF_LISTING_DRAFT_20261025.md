## 실제 상품 소개 문구 (QA 승인 이후 편집해서 사용)
사장님의 반복 업무, 작은 파일 하나부터 직접 정리해 보세요.

SMAX² SELF는 코딩 경험이 없는 분도 업무 자료의 구조를 살피고, 필요한 자동화 절차를 배우도록 설계한 **로컬 우선 셀프 업무 도구**입니다. 거래내역 CSV 파일의 거래일·상품명·금액 열을 직접 확인하여 정리하고, 누락·중복·날짜/금액 형식 오류는 **검토 대상**으로 표시할 수 있도록 개발 중입니다.

추가로 10개 업무 유형의 설계 가이드와 규칙형 질문·AI 구축 요청서 초안을 제공합니다. 이 10개는 모두 자동 실행되는 업무 프로그램이 아니라, 내 업무에 필요한 입력·조건·예외를 알아보고 직접 구축할 수 있게 돕는 **교육·설계용 템플릿**입니다.

## 반드시 공개해야 하는 제한
- CSV UTF-8 최대 2MB. Excel `.xlsx` 직접 입력/자동 변환 **미지원**. 필요 시 구매자가 CSV로 내보낸 뒤 사용.
- 실제 기능은 **CSV 자료 정리 1종**이며 다른 9개는 설계 템플릿. 주문·발주·결제·Gmail·ERP·웹크롤링을 본 제품이 직접 실행해 주지는 않음.
- 로컬 처리 우선. 전자상거래 외부 서비스 로그인이나 생성형 AI 유료 API 키는 기본 기능에 필요하지 않음. 사용자가 별도의 외부 AI에 내용을 붙여넣으면 제3자 전송이 발생할 수 있음.
- 변환 오류·중복·결측은 자동 판단하여 삭제하지 않고 검토 상태로 표시. 결과에 대한 회계·세무·법률 판단은 구매자/전문가 책임.
- 설치 불필요한 HTML 실행을 목표로 하나 Windows Edge/Chrome·보안 프로그램별 호환성 실제 QA 전에는 **확정 판매 문구로 기재 금지**. 스마트폰/맥 완전 지원도 미검증.
- 고객 원본 개인정보·영업자료를 상품 문의나 GitHub, 판매자 이메일로 요청하지 않음. 합성 재현 파일만 요청 가능하도록 운영 설계.
- 이 상품은 설치·자동화 대행 또는 원격 고객 PC 제어 서비스가 아님.

## 실제 등록 전에 필요한 창업자 결정·검수 게이트
1. 테스트: `npm run qa:release` PASS + 산출 HTML SHA, Windows 브라우저 E2E `PASS`, 10종 설명 정확성 확인.
2. 상품명/가격/구성품/대응 OS/최소 환경 확정. 최초 희망가 논의 이력은 **확정 가격이 아니므로 비노출**.
3. 저작권·사용권(개인/사업장·재배포·소스 열람), 업데이트/버그 수정 기간, 비동기 지원 수단/시간/횟수 결정. 단일 HTML의 실행 JS는 기술적으로 복사 가능하며 복제 차단 기능 미구현.
4. 파일 전달 방식·크몽 규정·안전결제·심사자료/스크린샷/샘플·실제 지원 가능 여부 검토. 크몽 고객을 외부 직접결제로 유도하지 않음.
5. 테스트 기록/상품 시연 영상·이미지는 **실제로 생성한 제품 화면**만 사용. 허위 후기·매출·제공 수량·검증 수치 주장 금지.
6. **창업자 최종 승인 후에만** 실제 등록/판매/배포 진행. 크몽 심사 통과일은 보장하지 않음.
