# SMAX 고객 참여형 셀프 AX 교육·실습 플랫폼 (2026-10-25)

> 최신 창업자 제안: SMAX는 **고객 참여형 + 교육형 + 셀프 AX 실습형**을 결합한 제품/공식 홈페이지. 기존 규칙 기반 로컬 코어, 10종 첫 템플릿, 50→100→1000 장기 확장, SELF 5만 원 + 선택 GUIDE 5만 원 방향은 유지. 여기서는 기획을 기록한 것이며 접수 시스템/실제품/홈페이지/Cloudflare 배포/판매는 아직 구현되지 않았음.

## 한 문장 제품 포지셔닝
**SMAX — 누구나 스스로 시작하는 AX. 배우고, 만들고, 함께 확장하는 자동화 라이브러리.**

1. **교육형:** 각 템플릿에 사장님의 실제 문제(합성 예시), 입력·출력 구조, 필요한 도구, 작업 지침, 실패/보안 주의, 테스트 방법을 포함하는 실습형 교재.
2. **셀프 AX형:** 고객 PC의 로컬 SMAX 엔진이 업무 유형 선택/템플릿 매칭→데이터 헤더/규칙 후보 매핑→누락 질문→사용자 확인→AX 설계 파일과 외부 AI 구축 프롬프트/단계별 체크리스트 생성. 고객이 자기 AI, n8n, Sheets 등을 직접 설정. 자체 유료 LLM 호출은 0원이 목표. 만능 자유문장 AI가 아님.
3. **고객 참여형:** 고객이 템플릿 목록을 보고 **없는 업무 자동화를 무료 제안**. 요청을 표준화·합성 사례로 변환하고 공통적이며 안전하고 검증 가능한 경우 우선 순위에 따라 추가해 **다른 사용자도 함께 사용**. 무료 제안·채택한 템플릿 추가 비용 0원을 목표로 하지만 **모든 요청의 구현/일정/개별 맞춤/정해진 갱신 권리까지 보장하지 않음**.

## 홈페이지의 정보 구조
- 첫 화면: 브랜드/AX 대중화/셀프 학습 의미, 실제 로컬 사용 화면 시연(검증 완료 여부 명확히).
- **템플릿 탐색:** 처음 10종의 사례를 필터(업무 분야·난도·도구)하고 각 상세에 입력 예시→표준화 규칙→AI 인계 명령→자가 구축 절차→테스트 방법 제공. 이후 50→100→1000종 목표.
- **참여형 요청함:** "찾는 템플릿이 없나요? 무료로 제안해 주세요. 공통 활용 가능성이 검증된 요청은 템플릿으로 만들어 모두와 공유합니다." 고객 원본 회사 파일/개인정보/거래처/내규/토큰/비밀번호 제출 금지. **일반 Contact/비즈니스 문의 창구는 열지 않음**.
- **인기와 진행 상태:** 조회/추천/요청 수 등 **실측 근거가 생기면 기간·기준을 명시한 순위**를 표시. 아직 측정 전에는 인기 TOP10이라고 과장하지 말고 "우선 소개 10종/편집 추천" 표시. 제안 상태는 접수→검토→채택/보류→제작→테스트→출시(채택/개발 보장 안 함). 개인정보 없는 공통 주제만 공개.
- 구매는 **실제 크몽에 등록된 상품 URL만** 홈페이지에서 링크. 비즈니스 문의/유료 서버/로그인/고객 자료 업로드 금지.

## 무료 제안 기능 구현 선택지와 운영 주의
- 정적 Cloudflare 홈페이지는 보여주는 것만 가능하며 **요청 접수·저장 기능은 별도 API/저장소 또는 공식 입력 채널이 필요**. Workers/D1 등을 쓸 경우 최소 저장·입력 검증·스팸/봇 대응·레이트 제한·안전한 관리/삭제/보관 정책·개인정보 고지를 검토. 백엔드 로컬 앱과 서버리스 '요청 접수'를 혼동하지 않는다.
- **14달력일 제품 개발 한도** 내 필수는 템플릿 교육/상세 UI와 동작 검증. 요청 폼이 준비되지 않으면 작동하지 않는 버튼을 만들지 말고 '기능 준비 중'을 표시. 실제 접수 허용 및 클라우드 계정 연결/배포/비용은 별도 출시 승인.
- 무료 요청이 폭주해도 고객에게 개별 구현/고객 실자료 처리/무제한 무상 개발을 약속하지 않는다. 검증·중복제거·일반화 가능한 지식을 추가하며 템플릿별 테스트/릴리스 기록을 남긴다.
- 기여자 표시는 **기본 익명**. 개인의 이름/닉네임/사업 내역 공개 및 소유권·보상 약속은 명시 동의/법적 검토 전 금지.
