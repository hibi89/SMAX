# SMAX 공식 홈페이지 · AX 연구소형 브랜드 쇼룸 제안 (2026-10-25 KST)

> **상태: 사용자 신규 사업 아이디어를 기록한 기획 제안. 구현/사이트 공개/유료 결제/도메인 구매/상품 등록 미착수.**
> 이 문서는 기존 14일 개발 상한, 로컬 제품, 무과금 API 원칙, 프라이빗 GitHub를 변경하지 않는다.
> 제품 공식 표기는 저장소 기준 `SMAX` (Self-Made AX). 음성 인식의 'SMEX'를 신규 상표 변경 결정으로 보지 않는다.

## 1. 사용자 신규 제안 요지
- SMAX 웹사이트는 무료 실사용 체험/업로드 데모 제공이 목적이 아님. **브랜드 전시장/디지털 기업 소개/독립 AX 연구소** 성격으로 사용.
- 실제 제공 가능하고 **검증된 로컬 프로그램**의 화면 녹화·업무 흐름 애니메이션·기능 상세를 고품질 인터랙티브 사이트에서 보여준다.
- 회사 소개: 소기업 사장님들이 적은 비용으로 자기 업무를 AX에 맞게 준비하고, DX→AX 과도기에서 한국의 AX 접근성 확대에 기여하겠다는 **비전**. 허위 고객 수/성과/공인 기관/법인 지위 주장을 하지 않는다.
- 로드맵: 앞으로 확장할 기능과 연구 주제를 '계획'으로 표시하며 이미 구현한 상품 기능과 구분.
- 비즈니스 문의: 사용자가 공개를 승인한 전용 메일 주소/문의 경로. 개별 회사 연락처나 미승인 개인 메일을 무단 공개하지 않음. 공개 문의폼은 개인정보 수집·스팸·보안 요건이 늘어나므로 초기에는 승인된 `mailto:`가 단순.
- **구매/후기/판매 실험은 크몽 등 외부 플랫폼**, 홈페이지에는 해당 플랫폼의 정책을 지키는 정식 구매 링크. 고객에게 플랫폼 외부 거래를 유도하는 방식 금지.
- 제품 자체는 고객 PC **로컬 실행, 기본 외부 LLM/API 호출 0**. 홈페이지에 데이터 분석 API/로그인/연간 과금 서버를 임의 구축하지 않는다.
- SMAX 브랜드는 기술 독점보다 **정직한 성능 시연, 사용자 피드백 기반 공통제품 개선, 저원가, 친숙한 신뢰, 장기 개발 역량**을 축적하는 방향.
- 무료 공개 체험을 강제하지 않되 제품 기능·한계·PC 요구사항을 정확히 알리는 **실제 동작 시연 영상**은 중요.

## 2. 권장 페이지 IA(정보 구조)
1. Hero: `누구나 시작할 수 있는 AX` 같은 짧은 메시지+브랜드 비전, 예시 애니메이션.
2. What SMAX Does: 회사 업무/자료→표준화→업무맵/규칙/데이터명세/AX-ready 산출물. **지원/미지원 범위를 명시**.
3. Product in Action: 실제 로컬 앱을 화면 캡처한 30~90초 핵심 흐름/긴 버전 링크. 설계 모션과 실기능 영상을 서로 표기해 혼동 금지.
4. Products: 현재 판매 중인 제품(실제 준비 완료 시), 지원 OS/기능/예외/가격·이용권·업데이트·환불 고지, 크몽 구매 링크(등록 완료 시).
5. AX Lab / Roadmap: 공개해도 되는 연구 방향·버전 변경 기록과 앞으로의 목표(계획/검증중/출시완료 레이블).
6. About / Vision: 독립 AX 연구 개발 스튜디오로서의 목표, 소상공인 DX→AX 접근성 확대, 현 실적을 과장하지 않는 약속.
7. Contact: 사용자가 별도 승인한 사업 전용 이메일 / 간단한 영업 문의. 처음부터 별도 SaaS 백엔드나 고객 데이터 수집 필요 없음.

## 3. 디자인·코드 자산 후보 (외부 의존성/라이선스 확인 필요)
- `frontend-design` SKILL.md: 의도적/독창적 화면 구성; 추상 'AI 티 안 나게'를 디자인 기준으로 구체화.
  - https://www.skills.sh/vercel-labs/open-agents/frontend-design
- Vercel `web-design-guidelines`: 접근성, 인터랙션, 기본 웹 완성도 검수.
  - https://vercel.com/design/guidelines
- `design.md`: 디자인 토큰/타이포/테마 규칙을 명세하는 별도 패턴, 교사가 말한 파일과 이름이 유사할 수 있지만 동일한 스킬인지 **미확인**.
  - https://www.skills.sh/ray0907/design-md-skill/design-md
- 시각적 참고: https://ui.aceternity.com/explore (애니메이션 컴포넌트), https://motion.dev/docs/react (스크롤/반응 모션).
- 외부에서 받은 SKILL.md나 UI 컴포넌트는 읽기 전용으로 출처/라이선스/보안 점검, 악성 스크립트·자동 데이터 송신·라이선스 위반 방지.
- 디자인 제안: 첨단 기술 이미지 + **사장님도 이해하는 쉬운 한국어**. 어두운 기술영역/미니멀 타이포, 과한 동작은 최소화, 모바일 우선·실영상 중심.
- UI 움직임은 React/Motion 또는 기본 CSS/JS로 생성할 수 있음. 무거운 3D와 긴 동영상은 성능/모바일 데이터 부담; 포스터 이미지, 클릭 재생, 동작 감소 환경 지원.

## 4. 배포 2안: Vercel vs 무료 상업 웹사이트
| 선택 | 초기 비용 | 사업 목적 운영 | 조건 |
|---|---|---|---|
| Vercel Hobby(개인/비상업용) | $0 | **불가** | 마케팅·상품 구매 링크·매출 목적이면 Vercel 약관상 commercial use. 사업용 공식 사이트로 사용 금지. |
| Vercel Pro | 월 $20부터 / 추가 과금 가능 | 가능 | 사용자가 지출·계정 변경 승인한 뒤만 |
| Cloudflare Workers Static Assets (Free) | 정적 페이지 요금 0 가능 | 검토 가능한 대안 | 정적 요청 무료·무제한(기타 한도/약관/계정 승인 확인). 고급 폼/서버 기능은 별도 제한. |

공식 근거:
- https://vercel.com/legal/terms (2026-10-19 업데이트; Hobby 개인·비상업 전용)
- https://vercel.com/docs/limits/fair-use-guidelines (commercial use 정의)
- https://developers.cloudflare.com/workers/static-assets/billing-and-limitations/ (정적 요청 무료·무제한)
- https://developers.cloudflare.com/workers/platform/limits/ (Free 제약)
**권장:** Vercel로 로컬 개발·비상업 내부 프리뷰 가능. 실판매 목적 공개 공식 홈페이지를 $0 월운영으로 유지하려면 Cloudflare Workers 정적 배포를 1순위로 비교. 정적 사이트 코드는 호스팅 독립적으로 작성하여 이후 Vercel Pro로 이동 가능하도록 설계. 사용자가 Vercel 유료를 승인하면 Vercel Pro도 선택지.

## 5. 14달력일 하드리밋과 출시 판단
- 기존 로컬 AX 제품 + 공홈을 **개발 착수 후 14달력일 이내**에 만들려면 기능 폭을 늘리지 말고 랜딩을 핵심 1페이지+영상+로드맵+연락·구매 링크로 한정한다.
- 화면 녹화는 실로컬 앱의 검증된 워크플로가 구현된 뒤 수행. 앱 기능 미구현 상태에선 개발예정 애니메이션임을 분명히 표시.
- 권장 사전 2안 비교: A) 정적 쇼룸 최소 구현 (SEO/속도/비용/관리 유리); B) 과다한 대시보드/3D/문의 DB (시간·성능·보안·유지비 증가). **A 추천**.
- 게시 전 요구: 실제 모바일·데스크톱 UI, 영상 기능 정합성, 링크·접근성·성능, 상표/도메인·연락처 공개 승인, 구매 링크 거래 규정, 개인정보·정식 사업자 표시 필요성 법적 확인.
- 사용자 승인 없는 공개 배포, 상업 호스팅 요금 결제, 메일 계정 생성, 외부 메일 발송, 온라인 스토어 등록 금지.
