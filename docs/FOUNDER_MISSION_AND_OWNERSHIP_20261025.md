# SMAX² Square — 창업자 미션과 운영 원칙

기록일: 2026-10-25 KST / 최신 사용자 결정 / 장기 방향성, 실적·매각가 보증 아님

## 핵심 미션
**저렴하고 접근하기 쉬운 AX로 대중화를 가속한다.**

- 미션: 소상공인과 일반인이 기술·비용 부담 없이 AX를 직접 배우고 활용하도록 돕는다.
- 브랜드: **SMAX Square / 스맥스스퀘어**, 표시 **SMAX²**. Square는 참여와 공유의 **광장**, ²는 배움과 자동화의 확산·가속. 'Multiplied'라는 단어는 공식 풀이가 아님.
- 표어: **혼자 시작하고, 함께 발전하는 AX 광장.**
- 공식 마스코트: 사용자가 선택한 연보라·하늘색·초록 새싹 로봇 **맥콩**. 어린이와 사장님 모두에게 친근한 안내자로 사용. 상업용 원본/권리·상표 확인은 별도.

## 성장과 소유
- 사용자가 처음에는 2~3년 내 기업가치 50억~100억 및 엑싯을 언급했으나, 즉시 **인수 후 지나친 상업화를 우려해 소유·운영 철학을 우리가 지키는 쪽으로 수정**. **최신 결정이 우선**.
- 기업가치 50억~100억은 미래의 목표치일 뿐 산정된 평가가 아님. **인수합병/매각을 기본 전략이나 종료 조건으로 삼지 않는다**.
- 제휴나 자본 조달은 서비스의 **가격 접근성·품질·교육 가치·IP·운영 주도권**을 훼손하지 않는 조건인지 검토한다. 영구 매각 금지와 같은 법적 약속을 생성한 것은 아님.
- 저가와 지속가능성은 양립하게 설계한다. 무조건 무료·원가 이하 공급을 약속하지 않는다.

## 제품 우선순위
1. **1차 (2026-10-25~11-07 목표): 사장님 존 / SELF**. 10종 템플릿 가이드·규칙 기반 스마트 검색·질문형 안내·로컬 파일 구조화, 실제 작동 가능한 소규모 현업 워크플로 1~2개 검증. GUIDE는 범위를 제한한 문자 학습 옵션. 크몽 안전결제 사용, 홈페이지는 소개·무료 시연 중심.
2. **2차:** 사용자 설치 부담을 줄이는 실제 웹 실행형 유료 WEB 템플릿. 로그인·서버 측 권한/보안·운영비와 거래 규정 확인 후 별도 개발.
3. **장기:** 학생·학부모의 저부담 AI 커리큘럼, 참여형 아이디어·템플릿 광장, 기존 공백상권 도구 소개, 교육기관/공공 파트너십. 미성년자 개인정보·보호자 동의·교육효과 검증 선행. 수주의뢰 거래 중개/5% 수수료·문구/굿즈는 아이디어로만 기록.
